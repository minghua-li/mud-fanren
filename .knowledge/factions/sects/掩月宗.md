## 一、宗门总览

| 项 | 内容 |
|----|------|
| 阵营 | 正道（越国七派） |
| 定位 | 七派魁首，法修/双修路线 |
| 地盘 | 掩月峰 |
| 代表人物 | 霓裳仙子（结丹领队）、穹老怪（结丹）、南宫婉（元婴） |
| LPC 门派标记 | `"sect": "yanyue_sect"` |
| 声望初始关系 | 中立（[[1D-门派种族声望]] §2.1） |

- 越国七大派中**实力最强**（原著：七派中掩月宗实力最强）。
- 提倡**双修之术**，所招弟子最起码一半是女性，**容貌不上等者绝不收录**（原著）。
- 标志性法器：**天月神舟**——巨型飞行法器，载人量大，七派齐聚时最为醒目（原著）。
- 灵根测试体系最为严谨（[[1D-门派种族声望]] §2.1.1）。
- 掩月宗是七派中**唯一有两位元婴修士**的门派，南宫婉为元婴期长老（[[1D-门派种族声望]] §2.1）。
