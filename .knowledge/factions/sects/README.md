## 二、开局势力分布

- **正道七派**：掩月宗、黄枫谷、灵兽山、清虚门、化刀坞、天阙堡、巨剑门，七派共治越国、互为同盟。
- **魔道两宗**：鬼灵门、御灵宗，同属天罗国魔道六宗，互为同盟。
- **灵兽山**名义属正道七派，实为御灵宗数千年前埋入越国的暗桩（原著第三卷），正魔大战中临阵倒戈。
- 越国七派整体实力弱于魔道六宗——六宗最弱的鬼灵门也比越国最强的掩月宗强三分（原著）。

## 五、开局选宗建议

- **丹修玩家** → 黄枫谷（丹药配方最全，韩立掌天瓶原型）。
- **御兽玩家** → 灵兽山（正道）/ 御灵宗（魔道），两宗同源。
- **阵修玩家** → 天阙堡（筑堡建州，阵法擅场）。
- **剑修玩家** → 黄枫谷（青元剑诀）/ 巨剑门（重剑）/ 清虚门（道剑）。
- **刀修玩家** → 化刀坞（刀修汇聚）。
- **魔修玩家** → 鬼灵门（血灵大法，暗灵根最佳）/ 御灵宗（虫兽双修）。
- **法修玩家** → 掩月宗（七派魁首，双修之术）。
