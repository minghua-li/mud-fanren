## 一、宗门总览

| 项 | 内容 |
|----|------|
| 阵营 | 正道（越国七派） |
| 定位 | 重剑碾压，体剑双修 |
| 地盘 | 巨剑峰 |
| 代表人物 | 万家先祖（散修出身） |
| LPC 门派标记 | `"sect": "jujian_gate"` |
| 声望初始关系 | 中立（[[1D-门派种族声望]] §2.1） |

- 越国七派之一，实力中等（原著：其余五派实力都差不多）。
- **全部男子**，人人一身黑衣，后背一把**一人高无鞘巨剑**，神色冷酷、煞气冲天（原著）。
- 剑修传承，重剑碾压路线（[[1D-门派种族声望]] §2.1.1）。
- 血禁试炼中巨剑门高人负责用石剑测试禁制强弱（原著）。
