## 一、宗门总览

| 项 | 内容 |
|----|------|
| 阵营 | 正道（越国七派，**暗为魔道暗桩**） |
| 定位 | 驱兽役虫，御兽驯灵路线 |
| 地盘 | 灵兽山 |
| 代表人物 | 云露（结丹） |
| LPC 门派标记 | `"sect": "lingshou_mountain"` |
| 声望初始关系 | 中立 → 敌对（正魔战后倒戈，[[1D-门派种族声望]] §2.1） |

- 越国七派中**实力第二**（原著：灵兽山紧随掩月宗之后）。
- **擅长驱兽役虫**，弟子服饰花哨、皮囊口袋众多、隐隐有活物鼓动（原著）。
- **暗为魔道六宗卧底**：数千年前御灵宗埋在越国的暗桩，正魔大战中临阵倒戈（[[1D-门派种族声望]] §1.2）。
- 驯养多种灵兽灵虫（金翅蚕、噬金虫等）。

## 七、地理与山门

- **灵兽山**：越国七派驻地，驱兽役虫。
- 山门遍布警戒虫网（彩蛾等），防范外敌。
