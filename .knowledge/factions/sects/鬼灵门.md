## 一、宗门总览

| 项 | 内容 |
|----|------|
| 阵营 | 魔道（天罗国魔道六宗） |
| 定位 | 驱鬼役妖，毒术暗术 |
| 地盘 | 天罗国 |
| 代表人物 | 王天古（元婴）、王蝉（少门主） |
| LPC 门派标记 | `"sect": "guiling_sect"` |
| 声望初始关系 | 敌对（与越国七派，[[1D-门派种族声望]] §6.3） |

- 魔道六宗之一，**六宗中最弱，但实力仍远超掩月宗**（越国最强）（[[1D-门派种族声望]] §1.2）。
- **驱鬼役妖、毒术暗术**（[[1D-门派种族声望]] §1.2）。
- 玄法精妙，燕家与其比试五场败四场（原著）。
- 以《万灵真经》副册+副门主之职拉拢燕家回归，结姻亲共修血灵大法（原著第三卷）。
