## 一、宗门总览

| 项 | 内容 |
|----|------|
| 阵营 | 魔道（天罗国魔道六宗） |
| 定位 | 万灵归宗，虫兽双修 |
| 地盘 | 天罗国 |
| 代表人物 | 曲魂 |
| LPC 门派标记 | `"sect": "yuling_sect"` |
| 声望初始关系 | 敌对（与越国七派，[[1D-门派种族声望]] §6.3） |

- 魔道六宗之一，**御兽之术**见长（[[1D-门派种族声望]] §1.2）。
- **与越国灵兽山有隐秘联系**——灵兽山原本是御灵宗的一个分支，数千年前魔道埋入越国的暗桩（原著第三卷）。
- 魔道讲究弱肉强食、强权真理（原著：曲魂语）。
- 与化刀坞修士斗法时威势惊人，方圆数里天翻地覆（原著）。
