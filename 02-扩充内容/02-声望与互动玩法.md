# 02：声望与互动玩法（游戏设计扩充）

> **本文档是对 [[factions/1D-门派种族声望]] 中声望系统和 [[factions/CHARACTERS]] 中角色互动体系的游戏化扩充**，聚焦玩家如何与各大势力互动、积累声望、解锁收益，以及玩家之间如何社交（好友/组队/交易/帮战）。
> 势力数值框架见 [[factions/1D-门派种族声望]]，角色关系图谱见 [[factions/CHARACTERS]]，势力总览见 [[factions/FACTIONS]]。

基于《凡人修仙传》剧本设定，面向 MUD 游戏化设计。本文档的内容属于「合理扩充」范畴。

---

## 一、声望系统总览

### 1.1 声望维度分类

凡人修仙传 MUD 采用多维声望体系，每个维度独立计算，共同决定玩家与世界的交互深度：

| 声望维度 | 覆盖范围 | 影响 | 存储 |
|---------|---------|------|------|
| **全局正道声望** | 全人界正道联盟 | 正道门派好感基础值，影响正道阵营任务准入 | 玩家全局属性 |
| **全局魔道声望** | 全人界魔道势力 | 魔道门派好感基础值，影响魔道阵营任务准入 | 玩家全局属性 |
| **具体门派声望** | 各门派内（越国七派/魔道六宗等） | 门派商店/任务/功法/晋升 | mapping key=门派ID |
| **种族声望** | 灵界诸族 | 种族互动权限、领地准入、跨族交易 | mapping key=种族ID |
| **区域声望** | 特定区域（乱星海/大晋/慕兰草原等） | 区域经济活动、传送阵使用权限 | mapping key=区域ID |
| **组织声望** | 独立组织（广源斋/天渊城等） | 组织专属商店、特殊任务链 | mapping key=组织ID |
| **凡人江湖声望** | 七玄门/野狼帮/墨府等 | 凡人阶段任务准入、江湖势力协助 | mapping key=江湖势力ID |

### 1.2 声望等级体系（游戏化）

基于 [[factions/1D-门派种族声望]] 的 7 级声望框架，游戏化后的表现如下：

| 等级 | 名称 | 数值范围 | 玩法效果 | 系统表现 |
|:---:|:----:|:--------:|---------|---------|
| -3 | **死敌** | ≤ -10000 | 见面即厮杀，NPC 主动攻击，不可交涉 | 红名闪烁，势力通缉令 |
| -2 | **敌对** | -9999 ~ -2000 | 进入领地即被攻击，商店封锁 | 名称变红，赏金猎人可接追杀任务 |
| -1 | **冷淡** | -1999 ~ -101 | 商店涨价 200%，仅有基础对话 | NPC 语气冷淡，拒绝请求 |
| 0 | **中立** | -100 ~ 100 | 正常交易，无特殊交互 | 默认态度 |
| 1 | **友善** | 101 ~ 2000 | 商店折扣 95%，接普通任务 | NPC 主动打招呼 |
| 2 | **信任** | 2001 ~ 8000 | 商店折扣 90%，接精英任务，购买限定物品 | 可进内部区域 |
| 3 | **尊敬** | 8001 ~ 25000 | 商店折扣 80%，核心功法/法宝开放，打折 | NPC 恭敬，获专属称号 |
| 4 | **崇拜** | 25001 ~ 80000 | 商店折扣 60%，独有传承/收徒资格/势力庇护 | 全势力成员行礼，可参与决策 |
| 5 | **传说** | > 80000 | 隐藏内容，可成亲传弟子/结义兄弟 | 独一无二的剧情分支 |

**设计原则：**
- 声望跨度的指数递增确保前期提升快、后期提升难
- 负数声望的惩罚要足够显著，让玩家认真对待每个势力的关系
- 崇拜以上为"传奇"区域——大部分玩家不会到达，为深度内容制造者保留

## 二、声望获取途径（玩法化）

### 2.1 势力日常任务循环

每个主要势力提供日常任务链，按难度和声望等级分层：

#### 日常任务层级

| 任务等级 | 解锁要求 | 单次声望 | 频率 | 内容举例 |
|---------|---------|:--------:|:----:|---------|
| **跑腿/送信** | 中立 | +5~+10 | 每天5次 | 在各势力据点之间传递消息 |
| **采集/收集** | 友善 | +10~+25 | 每天3次 | 收集灵药/矿石/妖兽材料 |
| **清剿/猎杀** | 友善 | +15~+40 | 每天2次 | 清剿指定区域的敌对势力或妖兽 |
| **讨伐/副本** | 信任 | +30~+80 | 每天1次 | 组队讨伐精英怪或小型副本BOSS |
| **秘密任务** | 尊敬 | +80~+200 | 每周3次 | 潜入敌对势力、窃取情报 |
| **史诗任务** | 崇拜 | +200~+500 | 每月1次 | 势力主线剧情分支任务 |

#### 任务刷新机制

```
每个势力每日任务池（以黄枫谷为例）：
  ┌─────────────────────────────────┐
  │  黄枫谷每日任务池（共8个槽位）      │
  ├─────────────────────────────────┤
  │  ① 送信→掩月宗（跑腿）     +5声望  │
  │  ② 百药园除草（采集）      +12声望 │
  │  ③ 清剿太岳山脉妖兽（猎杀）+20声望 │
  │  ④ 越国边境巡逻（讨伐）    +35声望 │
  │  ⑤ 寻找失踪弟子（采集）    +15声望 │
  │  ⑥ 灵矿守卫（讨伐）        +40声望 │
  │  ⑦ [信任解锁] 秘密运货    +60声望 │
  │  ⑧ [尊敬解锁] 潜伏灵兽山  +150声望 │
  └─────────────────────────────────┘
  每日随机刷新 4-6 个，难度和内容随服务器天数和势力状态动态变化
```

**轮换机制：**
- 每日0点刷新任务池
- 同一势力连续做相同任务，声望收益递减（第4次开始-20%，防刷）
- 冷却后（隔一天不做）恢复正常收益

### 2.2 资源捐献

捐献灵石、材料、功法是快速提升声望的捷径，但成本高昂：

| 捐献类型 | 捐献物 | 声望/单位 | 上限(每日) | 说明 |
|---------|-------|:---------:|:---------:|------|
| **灵石捐献** | 灵石 | +1/100灵石 | +500/日 | 最直接的捐献方式，效率低 |
| **材料捐献** | 妖兽材料/矿石/灵药 | +5~+50/件 | +1000/日 | 视材料稀有度和势力需求浮动 |
| **功法捐献** | 功法秘籍 | +100~+500/本 | +2000/日 | 势力未收录的功法加成更高 |
| **法宝捐献** | 法器/法宝 | +50~+300/件 | +1500/日 | 上古法宝/通天灵宝有额外加成 |
| **丹药捐献** | 成品丹药 | +10~+100/枚 | +800/日 | 高阶丹药贡献更大 |
| **情报捐献** | 敌对势力情报 | +50~+200/条 | 不限 | 情报真实性和重要性评估 |

**捐献浮动机制：**
- 每个势力有物资需求列表（每日刷新）
- 当前急需的物品可获得 1.5~3 倍声望加成
- 例如「黄枫谷今日急需止血草」→ 捐献止血草声望×2
- 超额满足需求后，需求度下降，加成恢复正常

### 2.3 战斗与击杀

| 行为 | 声望变动 | 适用势力 | 说明 |
|------|:--------:|---------|------|
| 击杀敌对势力普通成员 | +2~+10/人 | 击杀方势力 | 低收益，防刷 |
| 击杀敌对势力精英 | +20~+50/人 | 击杀方势力 | 有冷却（同目标24小时仅一次） |
| 击杀敌对势力头目 | +100~+500/次 | 击杀方势力 | 主要声望来源之一 |
| 击杀叛徒/清理门户 | +50~+200/次 | 本势力 | 本势力叛徒 |
| 势力战争中杀敌 | +10~+30/人 | 参战方 | 按战功结算，战争期间加倍 |
| 摧毁敌对据点 | +500~+2000/次 | 进攻方势力 | 重大事件声望 |
| 救援本势力成员 | +20~+100/次 | 被救方势力 | 视被救者地位 |
| 击败入侵者 | +30~+150/次 | 防守方势力 | 保卫领地 |

### 2.4 特殊事件

| 事件类型 | 声望收益 | 触发条件 | 说明 |
|---------|:-------:|---------|------|
| **势力危难援助** | +200~+1000 | 势力被攻击/遭遇天灾时 | 雪中送炭，声望倍率高 |
| **节日庆典** | +50~+200 | 特定日期 | 如修仙节、开派纪念日 |
| **修为突破** | +100~+500 | 玩家升级大境界 | 一次性加成 |
| **师门推荐** | +500 | 完成推荐任务链 | 一次性，各势力仅一次 |
| **升仙大会夺冠** | +1000~+3000 | 升仙大会胜出 | 全势力声望（本阵营） |
| **炼器/炼丹大赛** | +200~+800 | 副职竞赛胜出 | 相关势力声望 |
| **完成势力主线** | +500~+5000 | 势力剧情里程碑 | 一次性，不可重复 |

## 三、声望解锁与商店

### 3.1 声望商店体系

每个势力都有分层解锁的商店/宝库：

| 商店层级 | 解锁声望 | 出售内容 | 货币 |
|---------|:-------:|---------|:----:|
| **基础商店** | 中立(0) | 普通丹药、基础材料、低阶符箓 | 灵石 |
| **中级商店** | 友善(100) | 中阶法器、功法残篇、中级丹药 | 灵石+少量贡献 |
| **高级商店** | 信任(2000) | 高阶法宝、完整功法、稀有材料 | 灵石+贡献 |
| **核心宝库** | 尊敬(8000) | 镇派功法、通天灵宝部件、秘境钥匙 | 贡献+功勋 |
| **秘密仓库** | 崇拜(25000) | 独有传承、唯一道具、势力专属称号 | 贡献+特殊条件 |

**声望折扣浮动模型：**

```
折扣率 = 基础折扣率 × (1 + 势力繁荣度修正)

基础折扣率（按声望等级）：
  崇拜: 0.60（6折）
  尊敬: 0.80（8折）
  信任: 0.90（9折）
  友善: 0.95（95折）
  中立: 1.00（原价）
  冷淡: 2.00（2倍价）
  敌对: 3.00（3倍价）
  死敌: 无法交易

势力繁荣度修正（-10% ~ +20%）：
  势力鼎盛期: +0%（无修正）
  势力扩张期: -5%（额外优惠5%，鼓励加入）
  势力困难期: +10%（涨价10%，资源紧张）
  势力衰败期: +20%（大幅度涨价）
```

### 3.3 声望互斥关系

部分势力的声望存在天然互斥，提升一方必然降低另一方：

| 声望对 | 互斥强度 | 说明 |
|-------|:-------:|------|
| 正道阵营 ↔ 魔道阵营 | **强互斥** | 提正道声望→降魔道声望（系数0.3倍）；反之亦然 |
| 星宫 ↔ 逆星盟 | **强互斥** | 乱星海两大对立势力 |
| 灵兽山 ↔ 越国其他六派 | **单向剧降** | 灵兽山叛变后，声望自动转为敌对 |
| 正道盟 ↔ 魔道六宗 | **强互斥** | 大晋正魔对立 |
| 人族 ↔ 角蚩族 | **强互斥** | 种族仇恨，不可调和 |
| 九国盟 ↔ 慕兰法士 | **强互斥** | 边境战争状态 |
| 妖族 ↔ 角蚩族 | **弱互斥** | 提妖族声望→角蚩族-0.1倍 |
| 灵界妖族 ↔ 魔界 | **强互斥** | 界面战争自动拉低 |
| 广源斋 ↔ 任何势力 | **无互斥** | 中立商盟，与所有势力兼容 |

**互斥算法：**

```
当玩家在势力A获得+Δ声望时：
  若势力B与A存在强互斥关系：
    势力B声望 += -Δ × 0.3（扣减30%的获取量）
  若存在弱互斥关系：
    势力B声望 += -Δ × 0.1（扣减10%）

注意：声望扣减不会低于-10000（死敌下限），不会把正声望扣成负的
```

## 四、好友与社交系统

### 4.1 好友系统

#### 基础功能

| 功能 | 说明 |
|------|------|
| **添加好友** | 输入目标玩家ID或点击玩家→申请好友→对方确认 |
| **好友列表** | 显示在线状态、当前区域、简要状态（战斗中/闭关中/空闲） |
| **私聊** | 跨区域即时消息（消耗少量灵力，防刷屏） |
| **组队邀请** | 从好友列表直接邀请组队 |
| **传送请求** | 好友之间可请求传送到对方所在区域（消耗传送符/灵石） |
| **查看位置** | 查看好友当前所在区域（大地图定位） |
| **仇人/黑名单** | 屏蔽指定玩家消息、拒绝组队邀请 |

#### 好友上限

| VIP/等级 | 好友上限 |
|---------|:--------:|
| 默认 | 30人 |
| 筑基期 | 50人 |
| 结丹期 | 80人 |
| 元婴期+ | 120人 |

### 4.2 亲密等级

好友之间有独立的亲密值系统，通过互动提升：

| 亲密等级 | 所需亲密值 | 解锁功能 |
|:-------:|:---------:|---------|
| **点头之交** | 0 | 基础好友功能 |
| **常来常往** | 200 | 传送优惠、赠送礼物上限提升 |
| **道友之交** | 800 | 双修加速修炼（限异性）、共享任务进度 |
| **生死之交** | 3000 | 组队属性加成+5%、可代交任务 |
| **莫逆之交** | 10000 | 共享部分洞府权限、生死传送（救援） |
| **道侣/结义** | 30000 | 专属双人技能、共享灵石仓库、绑定传送 |

**亲密值获取方式：**

| 行为 | 亲密值 | 限制 |
|------|:-----:|:----:|
| 组队完成副本/任务 | +10~+30/次 | 每日同一队友上限+100 |
| 赠送礼物（灵石/丹药/材料） | +1~+20/件 | 视物品价值 |
| 双修（限阴阳道侣） | +50~+100/次 | 每日一次 |
| 互相救援（PVE濒死拉起） | +50/次 | 每日限3次 |
| 传功指导（高阶带低阶） | +20/小时 | 高阶者灵力消耗 |
| 邮件往来 | +1/封 | 防刷上限+10/日 |

### 4.3 好友互动玩法

| 玩法 | 说明 | 冷却 |
|------|------|:----:|
| **礼物赠送** | 赠送丹药/材料/法宝给好友 | 无限制 |
| **双修** | 异性道友结为道侣后，双人打坐修炼加速（阴阳调和） | 每日一次 |
| **合练功法** | 组队在特定灵脉点合练，双方经验加成 | 每周三次 |
| **神识传音** | 远距离紧急呼叫，消耗神识值 | 每小时一次 |
| **洞府拜访** | 访问好友的洞府，可使用其部分设施（炼丹炉/药园） | 每日一次 |
| **组队竞技** | 2v2/3v3 修仙对战 | 每日限3次 |
| **护送** | 高阶玩家护送低阶玩家穿越危险区域 | 无限制 |
| **收徒** | 高阶玩家收低阶玩家为徒，共享师徒任务奖励 | 同一玩家仅一次 |

## 五、组队与交易系统

### 5.1 组队机制

#### 队伍构成

| 位置 | 人数 | 职责 | 加成 |
|:----:|:----:|------|:----:|
| **队长** | 1人 | 组队/踢人/分配模式设置 | 额外+5%声望获取 |
| **队员** | 1~4人 | 常规战斗/任务参与者 | 组队经验加成（见下表） |
| **临时成员** | 不限 | 仅限特定副本/战争场景 | 临时组队，无长期加成 |

#### 组队收益模型

| 队伍人数 | 经验加成 | 声望加成 | 掉落率修正 |
|:-------:|:-------:|:--------:|:---------:|
| 2人 | +20% | 不变 | +10% |
| 3人 | +35% | +5% | +15% |
| 4人 | +45% | +10% | +20% |
| 5人（满员） | +50% | +15% | +25% |

**经验分配方式（队长可选）：**
- **平均分配**：所有人获得等额经验（适合水平相近队伍）
- **贡献分配**：按伤害/治疗/控制贡献比例分配（适合带新队伍）
- **自由拾取**：不控制分配，各自拾取（适合亲友队）

#### 组队匹配

| 匹配方式 | 说明 |
|---------|------|
| **好友组队** | 从好友列表直接邀请 |
| **附近组队** | 在同一区域的玩家自动显示在组队面板 |
| **副本匹配** | 在副本入口处选择「匹配队伍」，系统自动撮合同副本玩家 |
| **师徒匹配** | 高阶玩家发布带新任务，低阶玩家申请加入 |
| **世界喊话** | 消耗传音符在世界频道喊话组队 |

### 5.2 交易系统

#### 交易类型

| 类型 | 范围 | 税收 | 说明 |
|------|:----:|:----:|------|
| **面对面交易** | 同区域玩家 | 0% | 双方面对面打开交易窗口 |
| **邮件寄送** | 跨区域 | 5%灵石税 | 可寄送物品+灵石，需收件人签收 |
| **拍卖行** | 全服 | 10%手续费 | 挂单拍卖，价高者得 |
| **坊市摆摊** | 特定坊市区域 | 5%摊位费(按天) | 离线可继续售卖 |
| **黑市交易** | 仅限黑市区域 | 0%但无保障 | 可匿名交易，但被劫风险 |
| **宗门贡献兑换** | 本势力内部 | 0% | 用贡献值直接换物品（锁定不可交易） |

#### 交易限制

| 限制类型 | 规则 |
|---------|------|
| **境界限制** | 不可交易超过自身境界1阶以上的物品（防倒卖高级装备） |
| **绑定物品** | 部分物品「拾取绑定」或「装备绑定」后不可交易 |
| **每日交易上限** | 筑基以下：5000灵石/日；结丹：50000/日；元婴：500000/日 |
| **交易日志** | 所有交易记录留存7天（防诈骗/盗号追查） |
| **修为惩罚** | 非双修道侣之间的高频灵石交易会触发「非法交易」声望惩罚（-1声望/1000灵石） |

## 七、灵界种族外交博弈

### 7.1 种族声望机制

灵界种族声望是独立于人界门派声望的另一维声望体系：

| 种族 | 初始关系 | 提升方式 | 高声望好处 | 低声望后果 |
|:----:|:-------:|---------|-----------|-----------|
| **人族** | —（玩家所属） | 天渊城任务/界战功勋 | 高阶功法/圣皇殿资格 | 被通缉驱逐 |
| **妖族** | 友善 | 银月支线/猎杀角蚩族 | 妖族领地通行/妖族功法 | 关闭交易 |
| **木族** | 友善 | 资源援助/魔族防御 | 木族灵药/木系功法 | 拒绝入境 |
| **角蚩族** | 敌对 | 不可直接提升 | — | 见面即杀 |
| **海王族** | 不友好 | 海域贸易/解决纠纷 | 海域通行/水属性宝物 | 海族袭击 |
| **夜叉族** | 中立 | 血天大陆任务 | 夜叉族锻造/特殊材料 | 关闭商店 |
| **飞灵族** | 中立 | 风属性任务链条 | 飞行加速/风系功法 | 禁止空域通行 |
| **空鱼族** | 中立→崇拜(韩立线) | 韩立相关支线 | 空间秘术/传送优惠 | — |
| **晶族** | 中立 | 矿脉交易/晶族任务 | 晶体护甲/物理免疫材料 | 禁止采矿 |
| **云族** | 中立 | 炼器材料以物易物 | 炼器加成/云族法宝 | 谢绝交易 |

### 7.2 种族外交事件

#### 外交事件类型

| 事件类型 | 触发频率 | 内容 | 玩家决策 |
|---------|:-------:|------|---------|
| **边界冲突** | 每周随机 | 角蚩族劫掠队入侵人族边境 | 支援/旁观/趁火打劫 |
| **种族纠纷** | 每两周 | 两族间因资源/领地发生矛盾 | 调解/偏袒一方/煽风点火 |
| **资源发现** | 每月 | 新矿脉/灵脉被发现，多族争夺 | 加入一方勘探队/独吞情报 |
| **联盟提议** | 每季度 | 某族提议建立军事/经济联盟 | 支持/反对/中立 |
| **天灾事件** | 每季度 | 某族领地遭遇天灾（灵潮/地震） | 援助/贸易封锁/落井下石 |
| **外族入侵** | 半年随机 | 角蚩族大规模入侵 | 联军抵抗/撤退/投降 |
| **跨族拍卖会** | 每年一次 | 广源斋组织，各族珍品交易 | 参与竞价/提供拍品/劫掠 |

#### 外交博弈玩法

```
种族外交博弈流程（以人族↔妖族↔木族三方为例）：

1. 木族遭遇角蚩族劫掠，向人族求援
   └─ 玩家选择：
       ├─ 救援木族 → 木族声望+1000，妖族声望+200（同为盟方）
       │                  角蚩族声望-1500
       ├─ 按兵不动 → 木族声望-500，人族全局声望-200（见死不救）
       └─ 暗中勾结角蚩族 → 角蚩族声望+500（但暴露后人族声望-3000）

2. 妖族提议建立三族联合巡逻队
   └─ 玩家在妖族声望>尊敬时，可被派为谈判特使
       ├─ 谈判成功 → 三族声望各+2000，称号「外交使节」
       └─ 谈判失败 → 各-500，但获得「谈判失败的情报」可用于其他交易
```

**外交声望对冲模型：**

```
外交事件中，玩家每次重大选择会影响多个种族的关系：

总声望变动 = 基础声望 × 立场修正 × 势力重要性系数

立场修正：
  直接援助: 1.0（全量）
  间接支持: 0.5
  保持中立: 0.0
  反对: -0.5
  直接敌对: -1.5

势力重要性系数（由该势力在当前事件中的地位决定）：
  事件核心方: 1.5
  事件相关方: 1.0
  事件旁观方: 0.3（只受微小影响）
```

## 八、数值模型

### 8.1 声望获取速率控制

#### 每日声望获取上限

| 境界 | 每日声望上限（单势力） | 每日总声望上限（全势力） |
|:---:|:--------------------:|:---------------------:|
| 炼气 | 500 | 2000 |
| 筑基 | 2000 | 8000 |
| 结丹 | 6000 | 25000 |
| 元婴 | 20000 | 80000 |
| 化神 | 50000 | 200000 |
| 炼虚+ | 100000 | 500000 |

#### 声望获取效率曲线

```
声望获取效率 = 基础效率 × 等级效率修正 × 重复惩罚 × 活动加成

等级效率修正（以「友善→信任」阶段为1.0基准）：
  中立→友善（0~100）:    2.0（快速入门）
  友善→信任（100~2000）: 1.0（平稳阶段）
  信任→尊敬（2000~8000）: 0.6（减速区）  
  尊敬→崇拜（8000~25000）: 0.3（深度区）
  崇拜→传说（25000+）:    0.1（瓶颈区）

重复惩罚：
  同一任务连续做：
    第1次: 1.0（正常）
    第2次: 0.9
    第3次: 0.7
    第4次: 0.5
    第5次+: 0.3（几乎无收益，强制换任务）

活动加成（叠加，乘法叠加）：
  势力节日期间: 2.0
  势力战争期间: 1.5
  服务器双倍声望活动: 2.0
  首次完成该势力任务: 3.0（仅一次）
```

### 8.2 声望衰减模型

高声望若长时间不互动，会以以下规则衰减。衰减的目的是防止「刷到崇拜后永不联系」，保持声望的动态性：

| 声望等级 | 每日衰减值 | 衰减阈值 |
|:-------:|:---------:|:--------:|
| 崇拜(25000+) | -10/天 | 不低于25000（名义上掉级，但保底不掉到尊敬） |
| 尊敬(8000~25000) | -5/天 | 不低于8000 |
| 信任(2000~8000) | -3/天 | 不低于2000 |
| 友善(100~2000) | -1/天 | 不低于100 |
| 中立(-100~100) | 0 | 稳定态 |
| 冷淡以下 | +1~+3/天（回升） | 不高于-100（时间冲淡仇恨） |

**衰减免触发条件（满足任一即可）：**
- 7天内完成过该势力任意任务
- 14天内完成过该势力高级任务
- 30天内有该势力商店消费记录
- 当前有该势力的未完成任务

### 8.3 声望升级总成本估算

| 声望等级提升 | 所需净声望 | 任务次数估算 | 时间估算(轻度) | 时间估算(重度) |
|:----------:|:---------:|:----------:|:------------:|:------------:|
| 中立→友善 | +100 | 10次跑腿 | 1天 | 即时 |
| 友善→信任 | +1900 | 40次中级任务 | 7~10天 | 3~4天 |
| 信任→尊敬 | +6000 | 30次高级任务 | 20~30天 | 10~14天 |
| 尊敬→崇拜 | +17000 | 30次核心任务 | 60~90天 | 30~45天 |
| 崇拜→传说 | +55000 | 特殊史诗任务 | 半年以上 | 3~4个月 |

**设计意图：**
- 崇拜约等于「此势力深度玩家」标识，需要2~4个月日常投入
- 传说级仅留给极少数玩家，确保其含金量
- 时间估算差异体现日常投入多少、效率高低

## 九、关联系统

### 9.1 与区域玩法的关联

| 区域 | 关联势力 | 声望影响 | 说明 |
|:----:|---------|:--------:|------|
| **越国七派领地** | 本门派 | 区域活动声望加成 | 在本势力领地内做任务声望×1.2 |
| **乱星海区域** | 星宫/逆星盟/妖兽 | 区域声望解锁通行 | 区域声望<冷淡→传送阵封锁 |
| **大晋领域** | 正道盟/魔道六宗 | 阵营决定区域准入门槛 | 敌对阵营入城即被通缉 |
| **慕兰草原** | 九国盟/慕兰法士 | 双方声望决定通行 | 高声望可自由通行草原 |
| **灵界雷鸣大陆** | 人族/妖族/角蚩族 | 种族声望决定领地准入 | 角蚩族领地需要伪装进入 |
| **灵界血天大陆** | 夜叉/飞灵/血族等 | 种族声望决定交易许可 | 各中立族领地凭声望通行 |
| **天渊城** | 灵界人族联军 | 界战功勋=特殊声望 | 高声望可进核心区域 |

**区域声望互锁机制：**

```
玩家在某区域的权限由以下公式决定：
区域权限等级 = min(本阵营在该区域的势力声望等级, 玩家在该区域的个人声望等级)

例：玩家个人在星宫声望「崇拜」，但正道阵营与星宫关系「中立」
  → 区域权限等级 = min(崇拜(4), 中立(0)) = 中立(0)
  → 玩家在天星城的权限仅为「中立」，无法享受崇拜特权
```

### 9.2 与任务系统的关联

| 任务类型 | 声望要求 | 关联方式 |
|---------|:-------:|---------|
| **普通师门任务** | 中立 | 每日可做 |
| **精英师门任务** | 友善 | 更高奖励，门派贡献产出 |
| **势力主线任务** | 信任+ | 驱动势力剧情推进 |
| **隐藏任务** | 尊敬+ | 触发专属剧情/稀有物品 |
| **种族专属任务** | 种族友善+ | 灵界种族任务线 |
| **跨势力任务** | 至少一方友善 | 涉及两个势力的外交任务 |
| **帮战任务** | 本门派弟子 | 战争期间特有任务 |
| **叛徒清理任务** | 信任+ | 本势力叛徒追杀 |

### 9.3 与经济系统的关联

| 经济系统 | 关联方式 |
|---------|---------|
| **灵石经济** | 捐献灵石是声望提升的基本途径；声望折扣影响灵石消费效率 |
| **坊市物价** | 声望等级直接影响购买折扣（见3.1节），长期来看声望高=省钱 |
| **势力产业** | 势力控制的矿脉/坊市/灵脉的税收分红，分配给高声望成员 |
| **丹药产出** | 高声望势力提供高级丹药配方/稀有药材购买权限 |
| **法宝交易** | 核心宝库中的高级法宝只能用贡献兑换，不可交易 |
| **黑市经济** | 低声望玩家被迫通过黑市获取被封锁势力的商品（价格更高） |

**声望经济效益量化：**

```
声望对消费效率的影响（以购买10000灵石物品为例）：
  崇拜（6折）：实际支付 6000 灵石 → 节省 4000
  尊敬（8折）：实际支付 8000 灵石 → 节省 2000
  信任（9折）：实际支付 9000 灵石 → 节省 1000
  中立（原价）：实际支付 10000 灵石
  冷淡（2倍）：实际支付 20000 灵石 → 多付 10000
  敌对（3倍）：实际支付 30000 灵石 → 多付 20000
  （死敌：无法购买）

在频繁交易长期看来，每个势力的声望等级直接转化为经济效率。
一个「全崇拜」玩家与「全中立」玩家相比，
在高阶物品消费上可节省 30%~40% 的开支。
```

### 9.4 与战斗系统的关联

| 战斗场景 | 关联方式 |
|---------|---------|
| **门派战** | 声望决定能否参战，战功=声望 |
| **正魔之战** | 阵营决定敌我识别，高声望可指挥小队 |
| **妖兽讨伐** | 各势力发布猎杀任务，收益与声望挂钩 |

| **BOSS首杀** | 首杀带来大量声望（一次性） |
| **决斗/切磋** | 不影响声望，纯娱乐竞技 |

### 10.2 声望等级判定函数

```lpc
// 判定声望等级（返回 -3~5）
int query_reputation_level(string faction) {
    int rep;
    
    if (faction == "righteous")
        rep = righteous_reputation;
    else if (faction == "evil")
        rep = evil_reputation;
    else if (faction_reputation[faction])
        rep = faction_reputation[faction];
    else if (race_reputation[faction])
        rep = race_reputation[faction];
    else if (region_reputation[faction])
        rep = region_reputation[faction];
    else
        return 0;  // 未知势力→中立

    if (rep <= -10000) return -3;     // 死敌
    if (rep <= -2000)  return -2;     // 敌对
    if (rep <= -101)   return -1;     // 冷淡
    if (rep < 101)     return 0;      // 中立
    if (rep < 2001)    return 1;      // 友善
    if (rep < 8001)    return 2;      // 信任
    if (rep < 25001)   return 3;      // 尊敬
    if (rep < 80001)   return 4;      // 崇拜
    return 5;                          // 传说
}
```

### 10.3 声望折扣计算

```lpc
// 计算在指定势力的购买折扣（返回 0.0~3.0）
float query_discount(string faction) {
    int level = query_reputation_level(faction);
    float base;
    
    switch (level) {
        case -3: return -1.0;  // 死敌→无法交易
        case -2: base = 3.0; break;   // 敌对→3倍价
        case -1: base = 2.0; break;   // 冷淡→2倍价
        case 0:  base = 1.0; break;   // 中立→原价
        case 1:  base = 0.95; break;  // 友善→9.5折
        case 2:  base = 0.90; break;  // 信任→9折
        case 3:  base = 0.80; break;  // 尊敬→8折
        case 4:  base = 0.60; break;  // 崇拜→6折
        case 5:  base = 0.50; break;  // 传说→5折
        default: base = 1.0;
    }
    
    // 势力繁荣度修正
    mapping faction_status = FACTION_D->query_status(faction);
    int prosperity = faction_status["prosperity"];
    // prosperity: -2(衰败) -1(困难) 0(鼎盛) 1(扩张)
    float prosperity_mod;
    switch (prosperity) {
        case -2: prosperity_mod = 1.20; break;
        case -1: prosperity_mod = 1.10; break;
        case 0:  prosperity_mod = 1.00; break;
        case 1:  prosperity_mod = 0.95; break;
        default: prosperity_mod = 1.00;
    }
    
    return base * prosperity_mod;
}
```

### 10.4 日常任务声望计算

```lpc
// 计算完成某个任务获得的声望
int calc_task_reputation(string faction, string task_type, object player) {
    int base;
    float mod = 1.0;
    
    // 任务基础声望
    switch (task_type) {
        case "courier":  base = 5 + random(6); break;   // 跑腿 5-10
        case "collect":  base = 10 + random(16); break; // 采集 10-25
        case "hunt":     base = 15 + random(26); break; // 猎杀 15-40
        case "elite":    base = 30 + random(51); break; // 精英 30-80
        case "secret":   base = 80 + random(121); break;// 秘密 80-200
        case "epic":     base = 200 + random(301); break;// 史诗 200-500
        default: base = 10;
    }
    
    // 等级效率修正
    int level = player->query_reputation_level(faction);
    if (level <= 0) mod *= 2.0;          // 新手快速入门
    else if (level == 1) mod *= 1.0;     // 友善→信任
    else if (level == 2) mod *= 0.6;     // 信任→尊敬
    else if (level == 3) mod *= 0.3;     // 尊敬→崇拜
    else mod *= 0.1;                      // 崇拜以上
    
    // 重复惩罚
    int repeat_count = player->query("task_repeat/" + faction + "/" + task_type);
    if (repeat_count >= 5) mod *= 0.3;
    else if (repeat_count >= 4) mod *= 0.5;
    else if (repeat_count >= 3) mod *= 0.7;
    else if (repeat_count >= 2) mod *= 0.9;
    
    // 活动加成
    if (FACTION_D->is_festival(faction)) mod *= 2.0;
    if (FACTION_D->is_wartime(faction)) mod *= 1.5;
    
    return to_int(base * mod);
}
```

// 每日声望衰减处理（由守护进程定时调用）
void decay_reputation(object player) {
    int now = time();
    
    foreach (string faction, int rep in player->query("faction_reputation")) {
        if (rep <= 100 && rep >= -100) continue;  // 中立稳定区
        
        int last = player->query("last_interact/" + faction);
        int days = (now - last) / 86400;
        
        if (days < 7) continue;  // 7天内有过互动→不衰减
        
        int decay;
        if (rep > 25000)      decay = 10;   // 崇拜
        else if (rep > 8000)  decay = 5;    // 尊敬
        else if (rep > 2000)  decay = 3;    // 信任
        else if (rep > 100)   decay = 1;    // 友善
        else if (rep < -100)  decay = -2;   // 负声望回升（时间冲淡）
        else continue;
        
        player->add("faction_reputation/" + faction, -decay);
    }
    
    // 全局声望同样处理

}

## 十二、总结

### 12.1 核心设计原则

1. **声望是渐进式的交互深度**：从「认识你」到「生死之交」，逐层解锁内容，全程有获得感
2. **社交系统降低单人倦怠**：好友/组队/道侣提供情感连接和经济互助，减少单人挂机感
3. **声望互斥创造有意义的选择**：无法同时讨好所有势力，玩家必须做出取舍，形成差异化身份
4. **帮战/界战提供周期性的集体高潮**：日常积累的声望在战争日集中释放，形成游戏节奏
5. **数值控制防刷防崩**：每日上限、重复惩罚、衰减机制三重保障声望体系长期健康

### 12.2 实现优先级建议

| 优先级 | 内容 | 说明 |
|:-----:|------|------|
| **P0** | 声望等级判定 + 基础声望获取（任务/捐献） | 核心系统，所有玩法的基础 |
| **P0** | 好友系统 + 组队系统 | 最基础的社交功能 |
| **P1** | 声望商店 + 折扣模型 | 让声望产生实际价值 |
| **P1** | 门派战 | 越国七派间的基础PVP |
| **P2** | 正魔之战 | 大规模阵营战 |
| **P2** | 亲密等级 + 道侣系统 | 深度社交功能 |
| **P3** | 交易系统 + 拍卖行 | 经济系统配套 |
| **P3** | 种族声望 + 外交事件 | 灵界内容扩展 |
| **P4** | 界面战争 | 大后期玩法 |
| **P4** | 声望成就 + 外观系统 | 荣誉感装饰 |
