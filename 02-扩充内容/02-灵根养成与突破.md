# 02：灵根养成与突破系统（游戏设计扩充）

> **本文档是对 [[cultivation/CULTIVATION_SYSTEM]] 和 [[cultivation/1C-修仙境界功法]] 中灵根部分的游戏化扩充**，聚焦玩家如何检测、养成、突破灵根——灵根检测与生成、洗练途径、突破事件玩法化、灵根数值模型、以及与各子系统的联动。
> 原著灵根数据见 [[cultivation/1C-修仙境界功法]]，境界体系见 [[cultivation/CULTIVATION_SYSTEM]]。

基于《凡人修仙传》剧本设定，面向 MUD 游戏化设计。本文档的内容属于「合理扩充」范畴。

## 一、灵根系统总览

### 1.1 灵根品质体系

灵根按品质分为 6 档，决定玩家的修炼天花板和游戏体验走向：

| 品质 | 类型 | 属性数 | 修炼速度系数 | 结丹瓶颈 | 出现概率 | 玩家来源 |
|:---:|:----:|:-----:|:----------:|:--------:|:-------:|---------|
| T0 | **天灵根** | 1种纯属性 | ×2.5 | 自动结丹（无瓶颈） | 0.01%（数百年一遇） | 稀有 roll 点 / 特殊成就 |
| T1 | **变异灵根** | 变异属性 | ×2.3 | 正常瓶颈 | 0.05%（二三十年一个） | 稀有 roll 点 / 特殊机缘 |
| T2 | **真灵根** | 2-3种 | ×1.0 | 正常瓶颈 | ~15%（有灵根者中） | 正常创建 |
| T3 | **假灵根** | 3-4种 | ×0.6 | 瓶颈略难 | ~20% | 正常创建 |
| T4 | **伪灵根** | 4-5种杂 | ×0.3 | 几乎无望 | ~64.94%（绝大多数） | 默认/保底 |
| T5 | **无灵根** | 无 | ×0 | 无 | 凡人（占人口99.9%） | 凡人 NPC |

**设计原则**：品质的梯度差距必须显著，使玩家对灵根差异有强烈感知，同时后天养成系统提供明确的逆袭路径（见第三章）。

### 1.2 变异灵根子类型

| 变异灵根 | 基础组合 | 核心特点 | 匹配功法战力加成 |
|:-------:|---------|---------|:--------------:|
| **雷灵根** | 金+水变异 | 攻击最强，克制妖魔 | ×3.0（雷系功法） |
| **冰灵根** | 水+土变异 | 冰冻控制，防御力强 | ×2.5（冰系功法） |
| **风灵根** | 风属性变异 | 速度极快，身法优异 | ×2.5（风系功法） |
| **暗灵根** | 特殊变异 | 隐匿、吞噬类能力 | ×3.5（暗系功法·极稀有） |

### 1.3 灵根五行属性

| 属性 | 修炼特性 | 法术倾向 | 代表功法 |
|:---:|---------|---------|---------|
| **金** | 灵力精纯，突破稳定 | 单体高伤、破甲 | 《太白金章》 |
| **木** | 气血绵长，修炼持久 | 回复、持续伤害 | 《青木长生功》 |
| **水** | 法力充沛，变化多端 | 控制、持续输出 | 《玄水真经》 |
| **火** | 爆发迅猛，进度快 | 爆发、灼烧 | 《焚天诀》 |
| **土** | 根基扎实，不易走火 | 防御、反控 | 《厚土诀》 |

## 二、灵根检测与生成（玩法化）

### 2.1 创建角色时的灵根检测

#### 检测流程（游戏化）

```
┌───────────────────────────────────────────────────┐
│              灵根检测仪式（新手入门剧情）              │
│                                                     │
│  第1步：前往修仙门派的「测灵殿」                         │
│  第2步：将手置于「测灵碑」上                            │
│  第3步：灵根属性在七彩光芒中显现                         │
│  第4步：长老/管事给出评价（影响初始对话分支）               │
│  第5步：根据灵根品质，获得不同初始选择                     │
└───────────────────────────────────────────────────┘
```

#### 检测结果呈现（文本化）

| 灵根品质 | 系统反馈文本 | 环境反应 |
|---------|------------|---------|
| 天灵根 | 「七彩华光冲天而起！测灵碑嗡嗡作响！」 | 全场震惊，掌门亲自接见 |
| 变异灵根 | 「测灵碑上泛起异色灵光，属性变幻莫测」 | 长老惊叹，赐予入门优待 |
| 真灵根 | 「测灵碑上现出两道/三道颜色各异的灵光」 | 正常入门流程 |
| 假灵根 | 「灵光暗淡而驳杂，资质平平」 | 普通对待 |
| 伪灵根 | 「灵光微弱且浑浊，若非有灵根几乎不可察觉」 | 管事惋惜，建议考虑丹修路线 |
| 无灵根 | 「测灵碑毫无反应，你与修仙无缘」 | NPC只能进入世俗剧情线 |

#### 玩家初始获得方式

| 方式 | 说明 | 概率分布 | 备注 |
|------|------|:-------:|------|
| **固定创建** | 新手默认获得伪灵根 | 100%新玩家 | 保证人人可玩 |
| **天命 roll 点** | 随机重roll灵根品质（限创建时） | T4:64% / T3:20% / T2:15% / T1:0.8% / T0:0.2% | 每人最多10次免费roll |
| **血脉继承** | 选择成为修真家族后代 | 基础品质+1档（上限T2） | 需选特定出身 |
| **付费检测（可选）** | 后期通过特殊道具重新检测 | 精度提升，发现隐性变异灵根概率+5% | 不保底、真随机 |
| **特殊事件觉醒** | 游戏中特定剧情触发灵根觉醒 | 极低概率 | 详见第五章 |

### 2.2 灵根显示界面

玩家应能通过命令随时查看自己的灵根状态：

```
> cha linggen

═══ 灵根面板 ═══
品级：真灵根（★★★☆☆☆）
属性：[金] [木] × [水] × [火] [土]
　　　 ↑主属性

修炼速度倍率：×1.0（基准）
当前灵根强度：72/100（影响突破概率）
灵根精纯度：61%（影响法力质量）
下一级突破灵根强度需求：80
推荐功法系别：金属性 / 木属性
═══════════════
```

| 面板字段 | 说明 | 范围 |
|---------|------|:---:|
| 品级 | 灵根品质星级 | ★×1～6 |
| 属性 | 拥有的五行属性（主属性高亮） | 金/木/水/火/土/变异 |
| 修炼速度倍率 | 当前生效的修炼速度系数 | 0.3～3.0 |
| 灵根强度 | 灵根的纯粹程度，越高修行效率越好 | 0～100 |
| 灵根精纯度 | 法力质量的修正系数，影响法术威力 | 0%～100% |
| 推荐功法系别 | 系统根据灵根推荐的功法路线 | 依属性而定 |

## 三、灵根洗练途径（后天养成）

### 3.1 洗练途径一览

| 途径 | 消耗 | 效果 | 可重复 | 风险 |
|------|:----:|:----:|:-----:|:----:|
| **洗灵池浸泡** | 灵石×5000 + 门派贡献×2000 | 灵根强度+5～15 | 每月1次 | 低 |
| **净灵莲服用** | 净灵莲×1（天材地宝） | 灵根品质提升1档（上限T2） | 终生1次 | 无 |
| **洗髓丹** | 洗髓丹×n（炼丹产出） | 灵根强度+n×2，精纯度+n×1% | 丹毒限制 | 丹毒积累 |
| **补天丹** | 补天丹×1（顶级丹药） | 灵根品质提升1档（上限T1），精纯度+20% | 终生1次 | 极高炼制难度 |
| **天雷淬体** | 天雷竹汁×1 + 灵石×10000 | 概率使金水灵根变异→雷灵根 | 终生1次 | 失败则灵根受损 |
| **秘境机缘** | 特殊副本触发 | 随机获得灵根强化（属性+2～20） | 依副本CD | 秘境死亡惩罚 |
| **血脉觉醒** | 需要特定血脉道具 | 概率觉醒变异灵根/特殊体质 | 终生1次 | 低概率激活 |
| **功法重修** | 散功至炼气期 | 灵根精纯度+10% | 每大境界1次 | 修为归零 |

### 3.2 洗灵池系统（核心玩法）

洗灵池是玩家中期最稳定的灵根养成途径：

| 参数 | 说明 |
|------|------|
| **位置** | 各主城修炼区，需要传送 |
| **进入条件** | 筑基期以上 + 灵石×5000 + 门派贡献≥2000 |
| **冷却时间** | 游戏时间30天（现实约2~3天宣游） |
| **基础效果** | 灵根强度+5～15（随机），精纯度+1%～3% |
| **品质加成** | 真灵根额外+2强度，天灵根额外+5强度 |
| **丹药协同** | 浸泡前服用洗髓丹，效果×1.5 |

**玩法事件**：浸泡过程中有 10% 概率触发特殊事件：

| 事件 | 触发条件 | 效果 |
|:----:|---------|------|
| 「灵气潮汐」 | 随机 | 当次效果×2 |
| 「灵脉共鸣」 | 身处高阶灵脉区域 | 额外获得灵根强度+10 |
| 「洗灵池之灵」 | 极稀有（1%） | 灵根品质临时观察孔+1档（持续30分钟）→ 提供突破契机 |
| 「池底暗流」 | 随机 | 被迫中断，效果减半 |
| 「他人干扰」 | 洗灵池有人竞争 | 触发争夺事件（NPC/玩家） |

### 3.3 丹药洗练系统

#### 洗髓丹（日常养成核心）

| 属性 | 数值 |
|:----|:----|
| **丹方来源** | 门派丹房（筑基期任务解锁） |
| **材料** | 灵芝×3 + 百年黄精×2 + 灵石×500 |
| **炼制难度** | ★★☆☆☆（中级炼丹术） |
| **基础效果** | 灵根强度+2，精纯度+1% |
| **品质影响** | 上品：效果×1.5；极品：效果×2，附带灵根+5强度 |
| **丹毒** | 每颗积累 5% 丹毒（丹毒≥50% 后效果减半） |
| **每日上限** | 3颗（超过无效且丹毒额外+2%/颗） |

#### 补天丹（质变型·终生一次）

| 属性 | 数值 |
|:----|:----|
| **丹方来源** | 秘境「虚天殿」/ 宗门秘传任务 |
| **材料** | 万年灵芝×1 + 龙涎果×3 + 净灵莲×1 + 灵石×50000 |
| **炼制难度** | ★★★★★（需元婴期+顶级炼丹术） |
| **主效果** | 灵根品质提升1档（伪→假 / 假→真 / 真→变 / 变→天） |
| **副效果** | 精纯度+20%，灵根强度+30 |
| **限制** | 终生只能服用1次，第二次无效 |
| **服用条件** | 结丹期以上 + 当前品质≤真灵根 |

> **品质提升规则**：补天丹的品质提升是逐档的，不能从伪灵根直接跳到天灵根。这条路径为「伪灵根逆袭」提供了明确的、但极其昂贵的可行路径。

### 3.4 后天灵根品质提升全路径

```
伪灵根 (T4)
    │
    ├─ 洗髓丹长期积累 → 最高达到灵根强度上限95，品质不变
    │
    ├─ 净灵莲（终生1次）→ 假灵根 (T3)
    │
    └─ 补天丹（终生1次）→ 假灵根 (T3)
            │
            ├─ 补天丹 + 净灵莲（不可叠加，取最高）
            │
假灵根 (T3)
    │
    ├─ 功法重修×2 → 灵根精纯度达70% → 概率突破→ 真灵根 (T2) [上限]
    │
    └─ 补天丹 → 真灵根 (T2)
            │
真灵根 (T2) ←── 后天养成终点（大部分玩家的天花板）
    │
    └─ 补天丹 → 变异灵根 (T1) 或 天灵根 (T0) [极低概率]
            │
            └─ 传说级机遇 → 具体属性由玩家经历决定
```

**最终上限**：后天养成最多达到 **真灵根（T2）**——天灵根和变异灵根是先天决定的，后天补天丹有极低概率（<5%）突破至T1/T0。

## 四、灵根数值模型

### 4.1 灵根对修炼速度的影响

#### 基础修炼速度公式

```
每单位时间修为增长 = 基础修炼效率 × 灵根速度系数 × (1 + 功法匹配系数 + 丹药加成)
```

| 变量 | 说明 | 计算方式 |
|------|------|---------|
| 基础修炼效率 | 境界基准值（见境界体系） | 炼气=10 筑基=50 结丹=200 元婴=800 … |
| 灵根速度系数 | 灵根品质决定的基础倍率 | 见下方表格 |
| 功法匹配系数 | 灵根属性与功法属性的匹配度 | 主属性匹配+0.5 / 副属性匹配+0.2 / 不匹配-0.2 |
| 丹药加成 | 各类修炼丹药的叠加效果 | 黄龙丹+0.3 金髓丸+0.5 … |

#### 灵根速度系数明细

| 灵根品质 | 基准系数 | 匹配主属性功法 | 匹配副属性功法 | 不匹配属性功法 |
|:-------:|:-------:|:------------:|:------------:|:------------:|
| 天灵根 | ×2.5 | ×3.0（+0.5匹配增益） | — | ×1.5（只有单属性） |
| 变异灵根 | ×2.3 | ×2.8（变异专属） | ×1.8 | ×1.0 |
| 真灵根（双属性） | ×1.0 | ×1.5 | ×1.2 | ×0.5 |
| 真灵根（三属性） | ×1.0 | ×1.4 | ×1.1（×2） | ×0.6 |
| 假灵根（三属性） | ×0.6 | ×0.9 | ×0.7 | ×0.3 |
| 假灵根（四属性） | ×0.6 | ×0.8 | ×0.6（×2） | ×0.3 |
| 伪灵根 | ×0.3 | ×0.5 | ×0.4 | ×0.2 |

#### 精纯度对修炼效率的修正

```
实际修炼效率 = 基础修炼效率 × 灵根速度系数 × (1 - (1 - 精纯度) × 0.3)
```

精纯度 100% 时，无衰减；精纯度 50% 时，效率降至 85%；精纯度 0% 时，效率降至 70%。

### 4.2 灵根对突破概率的影响

#### 小境界突破概率公式

```
突破概率 = 基础成功率 × 灵根强度系数 + 丹药修正 + 功法修正 + 心魔抗性
```

| 参数 | 说明 | 范围 |
|------|------|:---:|
| 基础成功率 | 层数区间决定（见功法修炼体系） | 8%～90% |
| 灵根强度系数 | 灵根强度/100，平滑增益 | 0～1.0 |
| 丹药修正 | 服用对应丹药的加成 | -0.1～+0.3 |
| 功法修正 | 匹配功法的层数增益 | +0.05～+0.2 |
| 心魔抗性 | 修炼心法/佛门功法的抗性加成 | +0.05～+0.3 |

**示例**：7层→8层功法突破（基础55%），玩家灵根强度70（系数0.7），服用了护脉丹（+0.15），主修匹配功法（+0.1）：
- 总概率 = 55% × 0.7 + 15% + 10% = **63.5%**

#### 大境界突破概率公式

```
大境界突破概率 = 境界基础概率 × 灵根品质系数 + ∑(辅助修正)
```

| 参数 | 说明 | 示例值 |
|------|------|:-----:|
| 境界基础概率 | 该境界突破的原始难度（见境界体系） | 炼气→筑基=10% |
| 灵根品质系数 | 灵根品质对突破的修正 | 见下方表格 |
| ∑(辅助修正) | 丹药+功法+环境+护法的全部修正 | 筑基丹+15%，灵地+5%… |

#### 灵根品质系数

| 灵根品质 | 灵根品质系数 | 大境界突破修正 | 特殊规则 |
|:-------:|:----------:|:------------:|---------|
| 天灵根 | ×5.0 | 突破到结丹期自动成功 | 自动结丹（无瓶颈） |
| 变异灵根 | ×1.2 | 无额外修正 | 匹配变异功法时×1.5 |
| 真灵根 | ×1.0 | — | 基准值 |
| 假灵根 | ×0.7 | 每大境界-5% | — |
| 伪灵根 | ×0.3 | 每大境界-15% | 结丹概率低至0.3%以下 |

**天灵根自动结丹的特殊规则**：
1. 天灵根玩家达到筑基大圆满后，无需进行结丹突破判定
2. 自动进入结丹期，但需完成一段剧情（「天降异象·金丹自凝」）
3. 该特权仅限于结丹期，元婴期及以上仍需正常突破

**伪灵根结丹的特殊设计**：
- 基础结丹率已极低（约0.3%），但可通过以下方式提升：
  - 三转重元功二转 → +20%
  - 服用雪灵水+天火液 → +15%
  - 灵根精纯度≥80% → +5%
  - 特殊机缘（秘境「血色禁地」获得结丹灵物）→ +10%
- 上限约束：即使全部叠满，伪灵根结丹率也不超过50%

### 4.3 灵根对战斗属性的影响

#### 法术伤害修正

```
法术最终伤害 = 基础法术伤害 × (1 + 灵根属性加成 + 功法匹配加成 - 目标属性抗性)
```

| 灵根类型 | 匹配属性法术伤害加成 | 非匹配属性法术伤害加成 |
|:-------:|:-----------------:|:------------------:|
| 天灵根（主属性） | +50% | -20% |
| 变异灵根 | +80%（变异属性）/ +30%（基础属性） | -10% |
| 真灵根（双属性） | +20%（×2） | -15% |
| 假灵根 | +10%（各属性） | -5%（仅不匹配属性） |
| 伪灵根 | +5%（各属性） | 0% |

## 五、灵根突破事件的玩法化

### 5.1 灵根突破的事件机制

灵根不仅是静态属性，也可以通过「灵根突破事件」实现玩法化。当玩家灵根强度达到当前品质上限时，触发灵根突破事件：

#### 触发条件

```
灵根突破事件触发条件：
1. 灵根强度 ≥ 当前品质上限（伪灵根上限80 / 假灵根上限85 / 真灵根上限95）
2. 玩家等级 ≥ 筑基期
3. 当前无其他灵根突破事件进行中
4. 冷却CD已过（每次突破后需游戏时间1年）
```

#### 事件流程

```
┌─────────────────────────────────────────────┐
│              灵根突破事件流程                   │
│                                               │
│  触发 → 选择突破方式 → 突破判定 → 结果处理     │
│                                               │
│  第1步：自选突破方式（见下方表格）                │
│  第2步：系统计算突破概率并展示给玩家               │
│  第3步：玩家确认进行突破                          │
│  第4步：动画式文本描述突破过程                     │
│  第5步：成功/失败，分别处理结果                    │
└─────────────────────────────────────────────┘
```

### 5.2 突破方式选择

| 突破方式 | 消耗 | 基础成功率 | 可配合道具 | 特殊效果 |
|---------|:----:|:--------:|-----------|---------|
| **自然突破** | 无额外消耗 | 35% | 护脉丹 (+10%) | 失败后灵根强度-5 |
| **丹药辅助** | 洗髓丹×3 | 50% | 同上 | 失败后灵根强度-3 |
| **灵石灌注** | 灵石×5000 | 45% | 同上 + 灵石加倍 | 失败后灵根强度不变 |
| **天材地宝** | 特定天材地宝×1 | 70% | 护脉丹无效 | 失败后灵根强度-10（但可再试） |
| **秘境突破** | 秘境入场券×1 | 60% | 所有增益有效 | 失败无惩罚，但秘境CD重置 |

### 5.3 突破事件的随机分支

突破过程中，15% 概率触发随机事件分支，改变突破体验：

| 随机事件 | 触发概率 | 影响 |
|---------|:-------:|------|
| **心魔入侵** | 5% | 追加心魔战斗，胜利则突破概率+30%，失败则当前突破必然失败 |
| **天降机缘** | 3% | 自动成功，额外灵根强度+10 |
| **灵力暴走** | 4% | 突破结果不变，但获得临时 buff「灵力充沛」30分钟内消耗减半 |
| **瓶颈感应** | 2% | 系统提示本次突破概率极低，建议准备更充分再尝试 |
| **功法共鸣** | 1% | 所修功法临时提升1层（持续1小时），突破概率+20% |

### 5.4 突破结果处理

#### 成功结果

```
突破成功奖励（至少获得其一）：
┌──────────────────────────────────────────┐
│ 必得：灵根强度+10                          │
│ 概率：                                      │
│   ● 灵根精纯度+3%  (100%)                  │

│   ● 领悟被动「灵根共鸣」  (5%)              │

```

#### 失败结果

```
突破失败惩罚：
┌──────────────────────────────────────────┐

│       灵根强度-3（丹药辅助）               │
│       灵根强度不变（灵石灌注）             │
│       灵根强度-10（天材地宝）              │
│       无惩罚（秘境突破）                   │
│ 附加：                                     │
│   ● 10%概率触发「灵根震荡」：24小时内       │
│     修炼效率-30%                          │

│     概率-10%（持续1次突破）                │
│ 保护：                                     │
│   ● 灵根强度不会因失败降至品质要求以下       │

└──────────────────────────────────────────┘
```

### 5.5 灵根觉醒·特殊事件

在特定条件下，玩家可以触发灵根觉醒事件——这是突破系统的终极玩法：

| 觉醒类型 | 触发条件 | 结果 |
|---------|---------|------|
| **属性觉醒** | 单属性灵根+对应功法修炼至大圆满 | 灵根精纯度达100%，修炼速度+20% |
| **变异觉醒** | 金+水双属性 + 天雷竹汁 + 化神期 | 概率变异→雷灵根（需渡雷劫） |
| **血脉觉醒** | 特定血脉道具 + 灵根强度≥90 | 概率激活隐藏属性（变异/特殊体质） |
| **上古觉醒** | 秘境「上古遗迹」中触发 | 随机获得一项上古灵根特性（唯一） |

**觉醒事件的玩法流程**：

```
1. 触发 → 系统提示「你的灵根深处涌起一股古老的力量…」
2. 选路 → 玩家选择觉醒方向（若有多个可能性）
3. 考验 → 完成一个专属剧情/战斗任务
4. 结果 → 觉醒成功/失败，永久改变灵根属性
5. 沉淀 → 觉醒后需闭关7日（游戏时间）稳固灵根
```

## 七、平衡控制与设计原则

### 7.1 灵根系统的核心平衡约束

| 约束 | 规则 | 设计目的 |
|------|------|---------|
| **出生不平等，但后天可追** | 天灵根起步快，但伪灵根有最丰富的后天养成内容 | 给予低品质玩家充足的养成驱动力 |
| **成本曲线指数增长** | 每提升1档品质的消耗≈前档5倍 | 防止高品质膨胀过快 |
| **上限控制** | 后天养成最高到真灵根（T2），天灵根/变异灵根必须先天 | 保留稀有价值的不可替代性 |
| **丹毒极限** | 过度使用丹药会反噬 | 限制简单粗暴的「氪丹升级」 |
| **唯一性约束** | 净灵莲、补天丹终生1次 | 重大质变必须要有决策分量 |
| **概率兜底** | 连续3次突破失败后下次概率+20% | 防止极端非洲导致挫败弃坑 |

## 八、灵根事件剧本示例

### 8.1 伪灵根逆袭事件：「百炼成丹」

```
触发条件：伪灵根玩家同时满足：
  ① 筑基大圆满
  ② 三转重元功二转已完成
  ③ 持有雪灵水×1 + 天火液×1
  ④ 灵根强度≥75

事件流程：
  第1幕：「长老召见」——门派长老告知你伪灵根结丹的艰难，但指出一条古法路径
  第2幕：「灵物收集」——需要收集雪灵水+天火液（可交易/秘境产出）
  第3幕：「散功重修」——利用三转重元功将修为散至筑基初期（短期战力下降）
  第4幕：「丹田淬炼」——在灵脉交汇处服用雪灵水+天火液，以灵根强行引导
  第5幕：「概率突破」——以20%基础概率进行结丹判定（受灵根强度、丹药加成、功法修正影响）
  
  突破成功：文本描述「你的伪灵根在药力冲击下发生蜕变，灵光从浑浊变为清澈——你结丹了！」
  突破失败：描述「药力在体内冲撞，修为倒退到筑基中期，但你的灵根似乎比之前更坚韧了」
                     → 灵根强度+10（虽败犹荣）
```

### 8.2 变异觉醒事件：「惊雷入体」

```
触发条件：
  ① 金+水双属性真灵根
  ② 持有天雷竹汁×1
  ③ 化神期以上
  ④ 经历至少1次雷劫类战斗

事件流程：
  第1步：在雷雨天使用天雷竹汁，触发「天雷感应」
  第2步：系统提示「你的体内金水灵根在天雷竹汁作用下发生异动…」
  第3步：选择「引导天雷入体」或「压制异动」（前者概率变异，后者安全但错过机会）
  第4步：如选择引导→触发3波天雷淬体战斗（自动战斗可跳过）
  第5步：生存判定（全部3波天雷抗住）
  第6步：变异判定（基础30% + 灵根强度/200 + 抗雷能力/100）
  
  成功：金+水灵根融合→变异雷灵根
        「你的丹田之中，一道紫色雷光划破灵海——你觉醒了雷灵根！」
        获得：雷系功法修炼权限 + 辟邪神雷天赋
  失败：灵根未变异，但获得永久被动「雷抗+10%」
```

### 8.3 天灵根专属事件：「天命所归」

```

    自动成功，附带场景描写：「天际一道灵光贯穿大殿，测灵碑自鸣不已」
    额外奖励：筑基期即获得门派长老关注，解锁特殊任务线
  
  筑基期→结丹期：「金丹自凝」
    自动成功，附带一段打坐入定剧情
    额外奖励：结丹后直接获得一个专属法宝胚胎
  
  结丹期→元婴期：「无瓶颈仍需渡心魔」
    虽无修为瓶颈，但元婴期的心魔劫不可避免
    心魔强度 = 普通玩家的 150%（因天灵根者缺少磨砺）
```
