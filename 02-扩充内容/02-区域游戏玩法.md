## 一、区域设计总览

### 1.1 五大区域维度

每个区域的设计从五个维度展开，构成完整的玩法循环：

```
┌──────────────────────────────────────────────────────────┐
│                   区域游戏玩法五维模型                       │
│                                                            │
│  ① 交互玩法  ── 玩家在该区域能做什么（活动类型/FB/日常）     │
│  ② 数值模型  ── 境界门槛/产出等级/消耗曲线/概率分布        │
│  ③ 资源产出  ── 该区域产出的灵石/材料/丹药/功法             │
│  ④ 平衡控制  ── 准入条件/收益递减/垄断防护/风险递进        │
│  ⑤ 系统联动  ── 与战斗/炼丹/社交/经济/声望的接口          │
└──────────────────────────────────────────────────────────┘
```

## 二、秘境探险玩法

### 2.1 秘境类型体系

秘境（Secret Realm）是游戏中最重要的副本玩法载体。按触发方式与规模分为以下类型：

| 秘境类型 | 触发方式 | 参与规模 | 周期 | 典型代表 |
|---------|---------|:-------:|:----:|---------|
| **剧情秘境** | 主线任务触发 | 单人/小队(≤3人) | 一次性 | 血色禁地（炼气期） |
| **定时秘境** | 全局定时开启 | 多人(≤30人) | 数天一周期 | 虚天殿（结丹+）、广寒界（化神+） |
| **挑战秘境** | 玩家主动消耗凭证 | 单人/小队(≤5人) | 依凭证CD | 妖兽岛猎妖、魔金山脉 |
| **机缘秘境** | 概率触发/探索发现 | 单人 | 随机 | 古修士洞府、空间裂缝 |
| **争夺秘境** | 跨势力竞逐 | 跨势力多人 | 周期性 | 昆吾山、灵界矿脉 |

#### 2.1.1 秘境通用流程（以定时秘境为例）

```
┌──────────┐    ┌──────────┐    ┌────────────┐    ┌──────────┐
│  开启预告   │──→│  入口开放   │──→│  限时探索期   │──→│  秘境关闭   │
│  (全服公告)  │    │  (进入窗口) │    │  (核心玩法期) │    │  (结算/传送) │
└──────────┘    └──────────┘    └────────────┘    └──────────┘
                      │                  │
                      ↓                  ↓
                准入条件校验：       动态事件触发：
                · 境界检查           · 妖兽刷新
                · 秘境钥匙/凭证       · 宝物出土
                · 队伍检查           · 势力冲突
```

### 2.2 各经典秘境设计

#### 2.2.1 血色禁地（Lv.2 / 炼气期 / 剧情秘境）

| 项目 | 内容 |
|------|------|
| **位置** | 越国建州境内，被风属性古禁封闭的独立空间 |
| **进入门槛** | 炼气期（筑基以下） |
| **开启周期** | 每五年一次，越国七派联手开启 |
| **参与人数** | 七大派各派最多20名弟子（极限70~100人） |
| **核心产物** | 筑基丹主药—「凝液草」 |
| **基准死亡率** | ≈75%（极高危，非必死但淘汰率极高） |

**玩法设计：**

| 阶段 | 时长 | 核心玩法 | 风险等级 |
|:----:|:----:|---------|:-------:|
| 入口集合 | 30分钟 | 各派队伍在入口集合，七派结丹修士联手破禁 | 低 |
| 外层探索 | 2~3天 | 采集灵药、低阶妖兽战斗、躲避高阶妖兽 | 中 |
| 深处争夺 | 1~2天 | 筑基丹主药争夺、门派间PVP、地形机关 | 高 |
| 出口结算 | 关闭前 | 持有凝液草的玩家需安全到达出口，全服公告幸存名单 | 极高 |

**产出表：**

| 产物 | 出现区域 | 单次产量 | 获取概率 |
|:----:|:-------:|:-------:|:--------:|
| 凝液草 | 禁地内层 | 3~5株（总上限） | 需要采集技能≥60 |
| 低阶妖兽内丹 | 全区域 | 2~5枚 | ≈60%（击杀妖兽掉落） |
| 古修士遗物 | 遗迹废墟 | 1~2件 | ≈15%（探索随机发现） |
| 灵石（中品） | 矿脉点 | 10~50块 | ≈40%（采集获得） |

#### 2.2.2 虚天殿（Lv.3 / 结丹~元婴 / 定时秘境）

| 项目 | 内容 |
|------|------|
| **位置** | 乱星海某独立空间 |
| **进入门槛** | 结丹期以上 |
| **开启周期** | 数百年一次（游戏内可调整为季度/半年度活动周期） |
| **核心宝物** | 虚天鼎（洪荒古宝）、补天丹 |
| **折损率** | ≈60%（核心区域更高） |

**秘境结构：**

```
虚天殿（三层结构）
├── 外殿（入口层）
│   ├── 迷宫通道（简单机关，中低阶傀儡守卫）
│   ├── 第一试炼厅（考验灵力控制）
│   └── 传送至中层
├── 中殿（核心争夺层）
│   ├── 灵药园（珍稀灵药采集区，多支队伍争夺）
│   ├── 炼器室遗迹（可获得古宝残片/器胚）
│   ├── 第二试炼厅（考验神识/魂魄强度）
│   └── 传送至内殿
└── 内殿（最终层）
    ├── 虚天鼎存放地（核心争夺点）
    ├── 第三试炼厅（考验综合战力+运气）
    ├── 五行禁制阵（需五行属性队员协作破解）
    └── 离开传送阵（紧急逃脱用）
```

**参与模式：跨势力竞逐**

乱星海各大势力（星宫、极阴岛、六连殿、散修联盟）在秘境中自然形成竞争关系。玩家可选择：
- **代表势力入场** — 跟随所属势力队伍，产出按贡献分配
- **散修自由入场** — 独立行动，高风险高回报（可能被多方追杀）
- **临时联盟** — 不同势力的玩家可临时组队，出秘境后自动解散

**产出表：**

| 产物 | 产出位置 | 价值等级 | 获取条件 |
|:----:|:-------:|:-------:|---------|
| 虚天鼎（唯一） | 内殿 | 洪荒古宝 | 通过五行禁制阵+击败守鼎傀儡 |
| 补天丹 | 内殿药室 | 顶级丹药 | 1~3枚，需破解封印禁制 |
| 万年灵药 | 中殿药园 | 高 | 采集技能≥80 |
| 古宝残片 | 中殿遗迹 | 中~高 | 随机探索 |
| 高阶傀儡核心 | 外殿~中殿 | 中 | 击杀傀儡掉落 |

#### 2.2.3 妖兽岛猎妖（Lv.3 / 结丹~元婴 / 挑战秘境）

| 项目 | 内容 |
|------|------|
| **位置** | 外星海（乱星海通过天星城传送阵可达） |
| **进入门槛** | 筑基期可入，建议结丹期 |
| **消耗** | 传送费（天星城→妖兽岛：200灵石/次） |
| **模式** | 单人/小队（≤5人） |
| **核心产出** | 妖丹（炼丹材料+炼器材料） |

**妖兽等级与产出：**

| 妖兽等级 | 对应境界 | 妖丹价值 | 掉落材料 | 建议队伍配置 |
|:-------:|:-------:|:-------:|---------|:----------:|
| 1~3级 | 炼气~筑基 | 50~200灵石 | 兽皮/兽骨/兽血 | 1人 |
| 4~6级 | 结丹 | 500~3000灵石 | 妖丹+高阶材料 | 2~3人 |
| 7~8级 | 元婴 | 5000~20000灵石 | 稀有材料+概率出古宝 | 5人/需战术配合 |
| 9级+ | 化神+ | 极稀有 | 顶级材料 | 需元婴组队 |

**猎妖玩法流程：**

```
① 购买传送券（天星城传送殿）
    ↓
② 选择目标岛屿（按妖兽等级分为多个独立岛屿）
    ↓
③ 进入猎场（1小时限时逗留）
    ↓
④ 猎杀妖兽 / 采集灵药 / 探索遗迹
    ↓
⑤ 妖力值积累（击杀越多，高阶妖兽刷新概率越高）
    ↓
⑥ 传送返回 / 被击杀掉落物品
```

#### 2.2.4 广寒界（Lv.4~5 / 炼虚~合体 / 定时秘境·灵界版本）

| 项目 | 内容 |
|------|------|
| **位置** | 雷鸣大陆上空·独立空间（入口在地渊第一层） |
| **进入门槛** | 化神期以上，合体期以下 |
| **开启周期** | 每万年一次（游戏调整为年度大型活动） |
| **进入凭证** | 广寒令（每次出世数百块） |
| **参与模式** | 各族精英大混战 — 人/妖/角蚩/夜叉/飞灵等多族同场 |

**分层设计：**

| 区域层 | 灵气浓度 | 危险等级 | 核心产出 |
|:-----:|:-------:|:-------:|---------|
| 外层（灵气沼泽） | ×2 | ★★★ | 普通灵药、低阶古宝、废弃传送阵 |
| 中层（遗迹群） | ×4 | ★★★★ | 高阶古宝、金篆文残页、上古洞府 |
| 内层（战场核心） | ×6~8（部分狂暴） | ★★★★★ | 玄天之宝残片、练神术传承、完整金阙玉书页 |

**特殊规则：**
- 修为压制：合体期以上无法进入
- 限时逗留：空间持续约数月~数年，关闭前必须离开
- 自由PVP：全区域无安全区，击杀掉落部分物品
- 禁制陷阱：上古禁制随处可见，有探索/机关拆除玩法

### 2.3 秘境数值模型

#### 2.3.1 基础收益公式

```
单次秘境总收益 = Σ(基础产出 × 区域系数 × 难度修正 × 幸运因子)

其中：
  基础产出    = 该秘境类型标准产出（灵石/材料/经验）
  区域系数    = 秘境等级系数（Lv.2=1.0, Lv.3=2.5, Lv.4=5.0, Lv.5=10.0）
  难度修正    = 1.0 + (实际参与人数 - 推荐人数) × 0.1 （人多奖励更多但人均降低）
  幸运因子    = 0.5 ~ 2.0（基于玩家气运/灵根/随机波动）
```

#### 2.3.2 死亡概率模型

```
秘境死亡概率 = 基准死亡率 × (1 - 玩家境界/秘境建议境界)

例：血色禁地基准死亡率=75%，炼气中期(7)进入(建议=炼气9层)
  P = 75% × (1 - 7/9) = 75% × 0.22 ≈ 16.7%
  （实际因竞争和运气，≈70%淘汰率仍合理——多数并非死亡而是失败退出）
```

#### 2.3.3 极品产出保底机制

| 秘境等级 | 保底规则 |
|:-------:|---------|
| Lv.2 | 每轮至少1份筑基丹主药产出（全服总量控制） |
| Lv.3 | 每轮高概率产出1~2件古宝残片，小概率完整古宝 |
| Lv.4 | 广寒令持有者可进，宝物完全随机（无硬保底但总产出期望明确） |

## 三、洞府经营系统

### 3.1 洞府类型与品质

洞府是玩家在中后期的核心个人空间，兼具修炼加成、存储、生产功能。

| 洞府类型 | 获取方式 | 修炼加成 | 最大容量 | 可升级 | 典型位置 |
|---------|---------|:-------:|:-------:|:-----:|---------|
| **草庐/石室** | 门派分配/自行开辟 | ×1.0 | 小 | 否 | 黄枫谷弟子洞府 |
| **个人洞府（普通）** | 灵石购买/宗门贡献 | ×1.2~1.5 | 中 | 3次 | 太岳山脉/天星城 |
| **个人洞府（灵脉）** | 高额灵石/特殊贡献 | ×1.5~2.5 | 大 | 5次 | 天星城圣山腰/天渊城三山脉 |
| **宗门洞府（共享）** | 宗门驻地内 | ×1.0~1.3 | 共享 | 随宗门升级 | 门派驻地 |
| **秘境洞府** | 秘境探索发现 | ×1.5~3.0 | 中 | 有CD限制 | 广寒界/虚天殿等限时使用 |

### 3.2 洞府功能模块

```
个人洞府系统
├── 核心功能区（洞府本体）
│   ├── 打坐室（修炼速度加成）
│   ├── 储物室（物品存放，安全保护）
│   └── 休息室（HP/MP恢复加速）
├── 生产区
│   ├── 药圃（种植灵药，需灵土/灵泉）
│   ├── 炼器室（炼器成功率+5~15%）
│   ├── 炼丹室（炼丹成功率+5~15%）
│   └── 灵兽室（驯养灵兽）
├── 防御区
│   ├── 护府禁制（防偷窃/防入侵）
│   ├── 预警法阵（入侵警报）
│   └── 传送锚点（快速回府）
└── 装饰区（非必须，个性化）
    ├── 家具布置
    ├── 灵植装饰
    └── 战利品展示墙
```

### 3.3 药圃系统（洞府核心生产玩法）

| 土地品质 | 获取方式 | 种植速度 | 灵药品级上限 | 可扩展 |
|:-------:|---------|:-------:|:----------:|:-----:|
| 凡土 | 默认 | ×1.0 | 低阶（炼气） | 2块 |
| 灵土 | 门派贡献兑换 | ×1.5 | 中阶（筑基~结丹） | 5块 |
| 灵泉浇灌的灵土 | 特殊任务/购买 | ×2.0 | 高阶（结丹~元婴） | 8块 |
| 万年灵土 | 秘境产出/天价购 | ×3.0 | 顶级（元婴+） | 12块 |

**种植流程：**

```
① 获取种子（打怪掉落/采集/坊市购买）
    ↓
② 开垦土地（消耗灵石和体力，品质越高消耗越大）
    ↓
③ 种植（选择种下→浇水/施肥/除虫，需定期上线照料）
    ↓
④ 生长（真实时间，从数小时到数天不等）
    ↓
⑤ 收获（产出的灵药可用于炼丹/出售/门派贡献）
    ↓
⑥ 土地休整（收获3次后需休整or用肥料恢复肥力）
```

### 3.4 洞府经营数值模型

#### 3.4.1 洞府建设成本

| 洞府等级 | 灵石成本 | 贡献/声望 | 特殊材料 | 建筑时间 |
|:-------:|:-------:|:--------:|---------|:-------:|
| Lv.1（草庐） | 免费（门派配给） | — | — | 即时 |
| Lv.2（普通洞府） | 5,000 | 门派贡献×1,000 | 木材×50，石材×30 | 24h |
| Lv.3（灵脉洞府） | 50,000 | 门派贡献×5,000 | 灵木×20，灵玉石×10 | 72h |
| Lv.4（顶级洞府） | 200,000 | 声望×10,000 | 万年灵木×5，五行灵石×各10 | 7天 |
| Lv.5（圣地级） | 1,000,000+ | 特殊条件 | 须弥石，空间结晶 | 30天 |

#### 3.4.2 修炼加成模型

```
实际修炼速度 = 基础修炼速度 × 洞府加成系数 × 灵脉品质系数

洞府加成系数:
  Lv.1: ×1.0  |  Lv.2: ×1.2  |  Lv.3: ×1.5  |  Lv.4: ×2.0  |  Lv.5: ×2.5

灵脉品质系数:
  无灵脉: ×1.0  |  下品: ×1.2  |  中品: ×1.5  |  上品: ×2.0  |  极品: ×3.0
```

#### 3.4.3 洞府维护成本

| 维护项 | 周期 | Lv.1 | Lv.2 | Lv.3 | Lv.4 | Lv.5 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 灵石维护 | 每7天 | 0 | 100 | 500 | 2,000 | 10,000 |
| 禁制充能 | 每30天 | — | 500 | 2,000 | 10,000 | 50,000 |
| 药圃维护 | 每次种植 | 10 | 50 | 200 | 1,000 | 5,000 |

> **设计意图**：洞府维护成本随等级指数增长，防止顶级洞府被一人长期独占，鼓励玩家权衡「赚灵石 vs 闭关修炼」的时间分配。

## 四、宗门驻地玩法

### 4.1 宗门驻地类型

| 驻地类型 | 适合规模 | 核心功能 | 防御强度 | 可迁移 |
|---------|:-------:|---------|:-------:|:-----:|
| **山门驻地** | 初创（≤50人） | 议事厅+传功堂+简单坊市 | 低 | 是（消耗小） |
| **标准驻地** | 发展中（50~200人） | 全功能建筑+护山大阵 | 中 | 是（消耗大） |
| **核心驻地** | 大型（200~1000人） | 全部功能+灵脉洞府群+传送阵 | 高 | 否（固定） |
| **圣地** | 顶级（1000人+） | 独占秘境+跨界传送阵+顶级灵脉 | 极高 | 否（唯一） |

### 4.2 驻地建筑体系

```
宗门驻地建筑树
├── 核心建筑（必须建造）
│   ├── 议事大殿（门派管理/职位任免/外交）
│   ├── 传功堂（门派功法传授/修炼指导）
│   └── 仓库/金库（共享资源存储）
├── 功能建筑（按需建造）
│   ├── 炼丹阁（批量炼丹，成功率门派加成）
│   ├── 炼器坊（批量炼器，材料共享）
│   ├── 坊市（门派内部交易市场，抽税产生门派资金）
│   ├── 灵药园（高级灵药批量种植）
│   ├── 灵兽园（集体驯养灵兽）
│   └── 藏经阁（独门功法/秘术存放）
├── 防御建筑（必须建造）
│   ├── 护山大阵（核心防御，消耗灵石维持）
│   ├── 巡查哨塔（预警+范围攻击）
│   └── 传送阵（连通主要城市）
└── 特殊建筑（稀有）
    ├── 秘境入口（门派独占小型秘境）
    ├── 灵脉汇聚阵（提升全驻地修炼速度）
    └── 跨界传送阵（灵界宗门专属）
```

### 4.3 驻地攻防战玩法

#### 4.3.1 宣战机制

| 项目 | 规则 |
|------|------|
| **宣战条件** | 进攻方宗门等级≥防守方等级-1 |
| **宣战消耗** | 进攻方消耗宗门资金×(防守方等级系数) |
| **宣战周期** | 每周最多发起1次攻防战 |
| **防守优势** | 防守方享有护山大阵+主场加成 |
| **持续时间** | 2小时（或一方全部退出） |

#### 4.3.2 攻防流程

```
┌──────────────┐
│  ① 宣战阶段    │ 进攻方宗主发起宣战，消耗门派资金
└──────┬───────┘
       ↓
┌──────────────┐
│  ② 备战阶段    │ 双方各有24小时准备时间
│               │  防守方可加固阵法/储备灵石
│               │  进攻方可集结盟友
└──────┬───────┘
       ↓
┌──────────────┐
│  ③ 攻防阶段    │ 攻方需依次突破：
│               │  山门 → 外围哨塔 → 护山大阵节点(3个)
│               │  → 核心大殿（全部破坏即为胜利）
└──────┬───────┘
       ↓
┌──────────────┐
│  ④ 结算阶段    │
│  攻方胜：      │  夺走防守方部分资源/资金，驻地耐久度下降
│  守方胜：      │  获得防守奖励，进攻方资金被没收
└──────────────┘
```

#### 4.3.3 驻地破坏与修复

| 破坏程度 | 效果 | 修复成本 | 修复时间 |
|:-------:|------|:-------:|:-------:|
| 轻度（耐久80%~100%） | 修炼加成-5%，无功能损失 | 灵石×1,000 | 1小时 |
| 中度（耐久50%~80%） | 修炼加成-15%，部分建筑暂停 | 灵石×5,000 | 12小时 |
| 重度（耐久20%~50%） | 修炼加成-30%，多数建筑暂停 | 灵石×20,000 | 3天 |
| 濒毁（耐久<20%） | 全功能暂停，有被灭门风险 | 灵石×100,000 | 7天 |

#### 4.4.2 驻地收益模型

```
宗门驻地每日收益 = 灵石税收 + 产出价值 + 声望增长

灵石税收 = 门派成员数 × 平均在线时长 × 税率(0.5%~2%，由掌门设定)
产出价值 = 各生产建筑的基础日产量 × 效率系数
声望增长 = 基础威望 + 攻防战胜 + 任务完成数 × 系数
```

#### 6.4.1 组队加成公式

```
组队总经验 = 单份经验 × 人数 × (1 + 0.1 × (人数-1))

```

## 七、传送网络设计

### 7.1 整体架构

传送网络是连接各区域的核心基础设施，按规模和跨越范围分为五级：

| 传送等级 | 跨越范围 | 代表连接 | 消耗基准 |
|:-------:|---------|---------|:-------:|
| **Lv.0 城内瞬移** | 同一城市内部 | 天星城各层↔坊市/传送殿 | 50灵石 |
| **Lv.1 区域传送** | 同国家/海域 | 越国各派之间/乱星海各岛 | 100~500灵石 |
| **Lv.2 大陆传送** | 跨国家/海域 | 越国↔乱星海古传送阵 | 中品灵石+大挪移令 |
| **Lv.3 跨大陆传送** | 灵界各大陆之间 | 风元大陆↔雷鸣大陆 | 极品灵石+大乘权限 |
| **Lv.4 跨界传送** | 人界↔灵界 | 飞升接引 | 化神境界突破 |

## 九、平衡控制与反垄断

### 9.1 资源产出控制

| 控制手段 | 说明 | 应用区域 |
|---------|------|---------|
| **总量限制** | 全服/每周稀有材料总量固定 | 血色禁地凝液草（每周期3~5株） |
| **个人上限** | 每个玩家单位时间最多获取量 | 妖兽岛每日猎妖获得妖丹≤20枚 |
| **收益递减** | 同一区域连续停留收益逐步下降 | 外星海连续猎妖：第1h 100%，第2h 80%，第3h 50% |
| **境界门槛** | 超出境界过多收益大幅降低 | 元婴期去炼气区基本无收益 |
| **CD机制** | 秘境/副本有进入冷却 | 虚天殿百年一开（游戏内数月） |
| **独占率控制** | 同一玩家/队伍无法垄断关键产出 | 虚天鼎等唯一物品绑定拾取 |

### 9.2 区域经济平衡

```
灵石流入（产出）     vs     灵石流出（消耗）
─────────────────────────────────────────
秘境产出              →  传送费用
猎妖收入              →  洞府维护
交易利润              →  秘境门票
任务奖励              →  装备修理
                   →  丹药消耗
                   →  建筑建设
```

> **经济平衡指标**：保持灵石净流出略大于净流入，防止通货膨胀。同时通过区域等级越高、灵石产出也越高，鼓励玩家提升境界进入高阶区域。

### 9.3 势力平衡机制

| 机制 | 说明 |
|------|------|
| **自动制衡** | 某一势力过强时，敌对势力会联合对抗（系统事件） |
| **声望对冲** | 提升一方声望可能导致另一方声望下降 |
| **资源再分配** | 定时秘境/矿脉争夺战强制重新分配关键资源 |
| **联盟限制** | 最强势力无法与第二大势力结盟 |
| **新服保护** | 新玩家加入弱势势力获得额外增益 |
