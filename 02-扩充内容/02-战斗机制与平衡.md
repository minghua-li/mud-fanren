## 一、玩法维度

### 1.1 技能组合与施放系统

#### 技能分类与槽位

战斗技能分为三大类，玩家在战斗前需配置出战技能组：

| 技能类别 | 槽位数 | 代表技能 | 特点 |
|---------|:------:|---------|------|
| **主攻击** | 3 | 火弹术、金刃术、掌心雷 | 主动施放，消耗法力，有冷却时间 |
| **辅助/控制** | 2 | 缠绕术、冰冻术、御风诀 | 控制/增益/减益效果 |
| **防御/位移** | 2 | 土墙术、血影遁、水盾术 | 减伤、闪避、逃脱 |
| **绝招/阵法** | 2 | 大庚剑阵、颠倒五行阵、剑影分光术 | 高消耗大招，CD 较长 |

**配置规则：**
- 同一属性的技能最多占 2 个主攻击槽（防止单属性过度集中）
- 绝招/阵法槽只能放入对应境界已解锁的绝招
- 不同技能类别共享法力池，不单独设资源

#### 技能释放流程

```
玩家输入指令 → 判断条件（法力/冷却/目标/距离）
  → 成功：执行技能效果（伤害/控制/增益）
    → 进入冷却状态 → 扣减法力
  → 失败：返回失败原因提示
```

| 施放条件 | 检查项 | 失败反馈 |
|---------|-------|---------|
| 法力充足 | 当前法力 ≥ 技能法力消耗 | "你的法力不足！" |
| 冷却完成 | 距上次使用已超过冷却时间 | "技能还在冷却中！" |
| 目标有效 | 目标在射程内且可被攻击 | "目标太远了！" / "无法攻击该目标" |
| 状态正常 | 未被眩晕/冰冻/幻术等控制 | "你无法行动！" |

#### 技能连招机制

连招系统允许玩家将多个技能按特定顺序施放，触发额外效果：

| 连招组合 | 触发条件 | 额外效果 | 境界要求 |
|---------|---------|---------|---------|
| 冰封→金刃 | 冰冻术命中后接金刃术 | 破冰伤害 +150%，无视 30% 防御 | 炼气中期 |
| 缠绕→火弹 | 缠绕术命中后接火弹术 | 灼烧额外持续 3 回合 | 炼气后期 |
| 土墙→蓄力 | 土墙术生效后蓄力一回合下一击 | 下一主攻击技能暴击率 +40% | 筑基期 |
| 御风→剑芒 | 御风诀状态下施展剑芒 | 攻击次数 +1 | 筑基中期 |
| 五行轮转 | 连续使用金→木→水→火→土五行法术 | 最后一击附带五行崩坏（全属性抗性 -20%） | 结丹期 |
| 剑影→巨剑 | 剑影分光术后接巨剑术 | 巨剑实际攻击次数 = 剑影数 × 0.5 | 结丹后期 |

**高级技巧——半施法模式：**
参考韩立的火弹术独特用法，部分法术支持「半施法」模式：
- 火弹术凝而不发：消耗持续法力，近战接触造成灼烧
- 掌心雷蓄力：每蓄力一回合，伤害 +30%，最多蓄力 3 回
- 水盾持续维持：每回合消耗法力维持护盾，可与其他行动并存

### 1.2 五行克制策略

#### 五行相克基础规则

| 攻击方属性 | 被克属性 | 克制倍率 | 描述 |
|-----------|---------|:-------:|------|
| 金 | 木 | 1.5x | 金克木——金刃术对木属性目标伤害增加 |
| 木 | 土 | 1.5x | 木克土——缠绕术对土属性目标效果更强 |
| 土 | 水 | 1.5x | 土克水——土墙术对水属性法术有额外防御 |
| 水 | 火 | 1.5x | 水克火——冰箭术对火属性目标伤害增加 |
| 火 | 金 | 1.5x | 火克金——火弹术对金属性目标伤害增加 |

**相生关系（按相生链增益）：**

| 属性 | 相生对象 | 增益效果 |
|------|---------|---------|
| 金 | 水 | 金生水——金属性助益水属性法术效果 +10% |
| 水 | 木 | 水生木——水属性助益木属性恢复效果 +10% |
| 木 | 火 | 木生火——木属性助益火属性伤害 +10% |
| 火 | 土 | 火生土——火属性助益土属性防御 +10% |
| 土 | 金 | 土生金——土属性助益金属性穿透 +10% |

#### 五行策略深度

**单属性专精路线：**
- 优势：装备/技能可高度集中，属性加成易叠加
- 劣势：遇到克星属性时极为被动（克制抗性 -20%、伤害 -30%）
- 适合：愿意承受风险的爆发型玩家

**多属性平衡路线：**
- 优势：遇任何属性都有反制手段，适应性强
- 劣势：资源分散，单属性面板不如专精路线
- 适合：稳健型、PVP 竞技向玩家

**战前策略——属性侦查与调整：**
- 可通过天眼术探查目标的五行属性（不超过自身一个大境界可查）
- 战斗前可调整出战技能组，选择克制属性的技能
- 高境界玩家可炼制「五行属性切换」法宝（临时改变自身部分属性权重）
- 策略核心：**情报决定胜负**——侦查到对方属性后针对性配置技能组

#### 变异属性的五行定位

| 变异属性 | 五行归属 | 克制关系简述 |
|---------|---------|-------------|
| **雷** | 变异火 | 克制水/阴/鬼道，对常规五行无明确被克 |
| **冰** | 变异水 | 克制火/风，被雷克 |
| **风** | 变异木 | 克制土/雷，被冰克 |
| **阴/鬼道** | 变异土+水 | 被雷/火强力克制（2.0x），对常规五行有 1.2x |

### 1.3 阵法站位操作

#### 阵法战斗机制

阵法在战斗中分为「预设阵」和「临场阵」两种模式：

**预设阵法（战斗前布置）：**
- 玩家在进入战斗前即可完成阵盘布设
- 适用于洞府防守、团战前准备、伏击场景
- 耗时 10-30 秒 реаль时间（期间不可移动），受干扰可被打断

**临场阵法（战斗中即时布置）：**
- 战斗回合中消耗 1-2 回合布阵
- 布阵期间无法进行其他攻击行动
- 需要更高境界和阵法熟练度

#### 阵型与效果

| 阵型名称 | 类型 | 布阵时间 | 效果 | 维持消耗 |
|---------|------|:-------:|------|:-------:|
| 聚灵阵 | 辅助 | 3 回合（临场） | 每回合恢复法力 5% | 灵石 × 1/回合 |
| 颠倒五行阵 | 防御+幻境 | 5 回合（临场）/ 预备 | 五行伤害减免 30%，敌方位移受限 | 灵石 × 3/回合 |
| 天罡北斗阵 | 防御 | 2 回合（临场） | 全员防御 +20%，分摊伤害 | 灵石 × 2/回合 |
| 大庚剑阵 | 攻击 | 4 回合（临场）/ 预备 | 对范围内敌人持续剑气伤害 | 无灵石消耗，但占用飞剑 |

**多人组队阵法（3-5 人）：**

| 阵型名称 | 人数 | 站位要求 | 效果 |
|---------|:---:|---------|------|
| 三才阵 | 3 | 前二后一 | 前排分摊 70% 伤害，后排专注输出/治疗 |
| 四象阵 | 4 | 四方站位 | 每方获得对应属性加成（金攻/木愈/水控/火盾） |
| 五行阵 | 5 | 五方站位 | 完整的五行相生循环，全员获得属性增益连锁 |

#### 站位操作

战斗中的「站位」是位置相关的战术维度：

| 位置区域 | 影响 | 适用场景 |
|---------|------|---------|
| 前排（近战位） | 受攻击概率 +30%，近战技能伤害 +15% | 体修、剑修、高防御职业 |
| 中排（均衡位） | 受攻击概率正常 | 均衡型职业 |
| 后排（远程位） | 受攻击概率 -20%，远程法术伤害 +10% | 法修、辅助型职业 |

**位置变换操作：**
- 每回合可选择「前进/后退/左移/右移」一格
- 移动与技能施放不能在同一回合进行（需要牺牲一回合的输出或防御）
- 特殊技能可进行快速位移（御风诀、血影遁、雷遁）
- 位置影响阵法站位有效性 —— 阵法需要所有布阵者保持在指定位置一定回合才能激活

### 1.4 PVE 怪物 AI

#### 怪物行为分级

| AI 等级 | 行为模式 | 代表怪物 | 境界定位 |
|---------|---------|---------|---------|
| 低级（基础） | 随机攻击最近目标，无战术 | 低阶妖兽（火狼、冰蝠） | 炼气期 |
| 中级（战术） | 优先攻击低防目标，有属性倾向 | 高阶妖兽、魔道修士 | 筑基~结丹 |
| 高级（智能） | 判断局势、切换目标、技能组合 | 元婴老怪、万年妖修 | 结丹~元婴 |
| BOSS 级（剧本） | 多阶段战斗、召唤、护盾、狂暴 | 银翅夜鹏、六翼霜蜈蚣 | 元婴+ |

**低级 AI 行为规则：**
```
每回合：
  1. 若目标在攻击范围内 → 执行普攻
  2. 若目标离开范围 → 追击一步
  3. HP < 20% 时 → 有 30% 概率逃跑
```

**中级 AI 行为规则：**
```
每回合：
  1. 评估目标防御 → 选择防御最低者攻击
  2. 有技能就使用（技能优先级：控制 > AOE > 单体）
  3. 自身 HP < 30% → 有概率使用恢复/防御技能
  4. 被五行克制 → 尝试切换攻击属性
```

**高级 AI 行为规则：**
```
每回合评估：
  1. 目标状态 → 若被控制/弱化，优先集火
  2. 自身状态 → HP/法力/技能冷却
  3. 战场局势 → 队友存活数、敌方人数
  4. 行动选择：
     - 若可秒杀低血量目标 → 使用终结技
     - 若被包围 → 使用 AOE/位移脱困
     - 若队友倒地 → 尝试复活/召唤
     - 否则 → 按技能组合表执行连招
```

### 1.5 PVP 匹配规则

#### PVP 模式

| 模式 | 准入条件 | 战斗规则 | 胜负判定 | 奖励/惩罚 |
|------|---------|---------|---------|---------|
| **切磋** | 双方同意 | HP 降到 1 停止 | 一方认输/HP 归 1 | 无死亡惩罚，少量实战经验 |
| **生死斗** | 境界差 ≤ 1 个大境界 | 可击杀 | 一方死亡 | 胜者：获取对方 10-30% 携带灵石；败者：掉落 1-2 件装备（可被拾取） |
| **门派战** | 所属门派不同 | 阵营对抗，占点/杀敌计分 | 分数先达标/全灭对方 | 门派贡献 + 声望，死亡无额外惩罚 |
| **演武场** | 等级匹配制 | 公平环境（属性平衡到相近水平） | HP 归零 | 段位积分变动，赛季奖励 |
| **追杀令** | 目标有赏金（红名） | 自由 PK 不受惩罚 | 目标死亡 | 赏金奖励，红名减少 |

#### 匹配规则（演武场）

```
匹配流程：
1. 玩家选择段位匹配 → 进入匹配队列
2. 系统搜索同段位 ±1 小境界的在线玩家
3. 等待时间 < 30 秒 → 优先精确匹配
4. 等待时间 ≥ 30 秒 → 放宽至差 ±2 小境界
5. 等待时间 ≥ 60 秒 → 放宽至任意境界（平衡补偿机制激活）
6. 匹配成功 → 传送至独立演武场副本 → 准备时间 10 秒 → 战斗开始
```

**段位系统：**

| 段位 | 入门积分 | 匹配范围 | 赛季奖励 |
|------|:-------:|---------|---------|
| 炼气（一至九层） | 0 | 同段位 | 灵石 × 50 |
| 筑基（初/中/后） | 500 | 同段位 ±1 层 | 灵石 × 200 + 筑基丹碎片 |
| 结丹（初/中/后） | 1200 | 同段位 ±1 层 | 灵石 × 500 + 凝液丹 |
| 元婴（初/中/后） | 2000 | 同段位 | 灵石 × 2000 + 稀有材料 |
| 大乘 | 3000+ | 全段位挑战 | 专属称号 + 法宝觉醒材料 |

**积分增减：**
```
胜：+15 ~ +25 积分（对方段位越高加成越多）
负：-5 ~ -15 积分（对方段位越低扣分越多）
连胜：（3 连 + 5 额外，5 连 + 10 额外，10 连 + 20 额外）
```

## 二、数值维度

### 2.1 五行相克数值公式

#### 克制系数计算

```
有效伤害 = 基础伤害 × 五行系数 × 境界系数 × 防御减免

五行系数 = 1.0 （无克制关系）
         1.5 （克制目标属性）
         0.7 （被目标属性克制）
         1.2 （变异属性对常规属性常规克制）
         2.0 （变异属性对极端克制目标，如雷克鬼道）

境界系数 = 1.0 （同境界）
         max(0.5, 1.0 - (目标境界 - 自身境界) × 0.15) （越级挑战）
         min(2.0, 1.0 + (自身境界 - 目标境界) × 0.2) （压制低阶）
```

#### 境界压制系数表

| 境界差 | 越级挑战方系数 | 压制方系数 |
|:-----:|:-------------:|:---------:|
| 同境界 | 1.0 | 1.0 |
| 差 1 小层 | 0.85 | 1.2 |
| 差 1 大境界 | 0.50 | 2.0 |
| 差 2 大境界 | 0.25 | 无法命中/可忽略 |

**突破压制的手段（韩立式越级打法）：**
- 使用顶级法宝（法宝等级 > 自身境界）→ 境界压制系数降低一个等级
- 多种法术/剑诀组合 → 每多一个攻击维度，对方防御有效性 -5%
- 阵法辅助 → 在阵内战斗，无视 1 小层境界压制
- 符宝/丹药爆发 → 短时间内提升一个境界的战斗力
- 神识压制 → 若神识属性强于对方，对方防御系数 -0.1

#### 属性穿透与抗性

```
最终抗性 = 基础抗性 + 属性抗性

属性抗性：
- 自身属性相同：对该属性伤害有 15% 天然抗性
- 自身属性被克：被克属性伤害 +20%
- 修炼对应功法：额外获得 5-10% 对应属性抗性
- 装备附带抗性：按装备品质 5-25%

穿透率 = 攻击方属性精通 × 0.1%  + 技能固定穿透
最终伤害减免 = max(0, 最终抗性 - 穿透率)
```

### 2.2 伤害计算模型

#### 基础伤害公式

```
物理/剑诀伤害 = (攻击方攻击力 × 技能基础倍率 - 目标防御力 × 0.5)
              × 技能等级系数 × 属性系数 × 境界系数 × 随机因子(0.95~1.05)

法术伤害 = (攻击方法力 × 技能法术倍率 - 目标法术抗性 × 0.3)
          × 技能等级系数 × 灵根加成 × 属性系数 × 境界系数 × 随机因子(0.95~1.05)

剑阵伤害 = (飞剑数 × 单剑攻击力 × 剑阵倍率)
          × 剑阵完整度系数 × 境界系数 × 随机因子(0.9~1.1)

神识伤害 = (攻击方神识强度 × 技能倍率 - 目标神识抗性)
          × 大衍诀层数系数 × 随机因子(0.8~1.2)
```

#### 技能等级系数

| 技能等级 | 系数 | 说明 |
|:-------:|:---:|------|
| Lv 1-20（入门） | 0.3-0.8 | 基础伤害爬坡 |
| Lv 21-60（熟练） | 0.8-1.2 | 正常伤害曲线 |
| Lv 61-100（精通） | 1.2-1.8 | 高阶伤害，解锁特殊效果 |
| Lv 100+（圆满） | 1.8-2.5 | 额外解锁连招/穿透/暴击属性 |

#### 灵根加成系数

| 灵根类型 | 基础伤害倍率 | 对应属性法术额外加成 |
|---------|:----------:|:-----------------:|
| 天灵根 | 1.5 | 对应属性 +30% |
| 真灵根 | 1.0 | 对应属性 +15% |
| 伪灵根 | 0.6 | 对应属性 +5% |
| 变异灵根 | 1.3 | 变异属性 +25%（常规属性 -10%） |

#### 暴击/会心系统

```
暴击率 = 基础暴击率(5%) + 装备暴击率 + 技能固定暴击率
暴击伤害 = 普通伤害 × (1.5 + 暴击伤害加成%)

会心一击（法术暴击）= 法术版的暴击
会心率 = 神识强度 / (神识强度 + 目标神识强度) × 10%
会心伤害 = 法术伤害 × 2.0
```

#### 特殊伤害类型

| 伤害类型 | 计算方式 | 特点 |
|---------|---------|------|
| **真实伤害** | 固定数值，无视防御 | 毒素/天劫/心魔伤害 |
| **持续伤害（DOT）** | 每回合造成固定伤害，持续 3-5 回合 | 灼烧/冰冻/中毒 |
| **百分比伤害** | 目标最大 HP 的百分比 | 大庚剑阵、天劫 |
| **剑气伤害** | 攻击力 × 剑气技能倍率，可叠加 | 无形剑气、青元剑诀 |
| **神识冲击** | 神识伤害 + 打断效果 | 打断施法（若神识差 > 20%） |

### 2.3 技能冷却与消耗

#### 法力消耗模型

```
技能法力消耗 = 基础消耗 × 境界消耗系数 × 技能等级修正

境界消耗系数：
  炼气期：1.0（基础）
  筑基期：0.85（法力池更大，相对消耗更小）
  结丹期：0.70
  元婴期：0.55
  化神+：0.40

技能等级修正：
  Lv 1-20：1.0 - 0.5%（每级减 0.5%，代表熟练后更高效）
  Lv 21-60：0.9 - 0.2%（每级减 0.2%）
  Lv 61-100：0.82 - 0.1%（每级减 0.1%）

示例：火弹术（基础消耗 20 法力）
  炼气期 Lv 1：20 × 1.0 × 1.0 = 20
  筑基期 Lv 50：20 × 0.85 × 0.82 = 13.9 ≈ 14
  结丹期 Lv 100：20 × 0.70 × 0.72 = 10.1 ≈ 10
```

#### 冷却时间模型

| 技能类型 | 基础冷却（回合） | 冷却缩减来源 |
|---------|:--------------:|-------------|
| 普攻/基础法术 | 0（每回合可用） | — |
| 中级法术 | 2-3 回合 | 灵根品质（天灵根 -1），丹药增益 |
| 高级法术 | 5-8 回合 | 大衍诀层数（每层 -0.5 回合） |
| 绝招/剑阵 | 10-20 回合 | 专属装备（如青竹蜂云剑对剑阵 -3 回合） |
| 阵法布设 | 战斗中仅一次 | — |
| 保命技（血影遁等） | 30 回合（现实 5 分钟） | 无 |

#### 法力恢复模型

```
基础法力恢复 = 最大法力值 × 1%/回合（静立）
               最大法力值 × 0.5%/回合（持续战斗中）
               最大法力值 × 3%/回合（打坐状态）

药物/丹药恢复：
  回灵丹：恢复法力 20%，冷却 5 回合
  聚气散：每回合恢复 5%，持续 5 回合
  天元丹：瞬间恢复 50%，CD 30 回合（战斗限 1 次）

阵法恢复：
  聚灵阵：每回合恢复 5%，持续占用布阵者行动
```

## 四、平衡控制

### 4.1 战斗时长控制

| 战斗类型 | 目标时长 | 控制手段 |
|---------|:-------:|---------|
| PVE 普通怪物 | 2-5 回合 | 怪物 HP = 玩家同境界普攻 3-5 次可击杀 |
| PVE 精英怪物 | 8-15 回合 | 精英 HP = 普攻 15-25 次，有特殊机制 |
| PVE BOSS | 20-40 回合 | 多阶段设计，每阶段切换行为模式 |
| PVP 切磋 | 5-15 回合 | 伤害平衡到 15 回合决胜，防御续航可延长 |
| 阵法战斗 | 10-25 回合 | 阵法持续消耗灵石，逼使玩家主动进攻 |

**DPS 平衡基线：**

```
基础假设：同境界玩家 vs 同境界标准怪物
  普攻伤害 ≈ 怪物 HP 的 20%
  技能伤害 ≈ 怪物 HP 的 25-40%（耗法力）
  绝招伤害 ≈ 怪物 HP 的 60-80%（长 CD）

同境界 PVP 平衡：
  玩家 HP = 5-8 次普通攻击可击杀
  治疗/恢复效率 = 单次治疗 ≈ 15-20% HP，CD 3-4 回合
  控制技能持续时间 = 1-2 回合（避免无限控制）
```

### 4.2 五行平衡

| 属性 | 理论强度 | 实际限制 | 平衡手段 |
|------|:-------:|---------|---------|
| 金 | 单点爆发最高 | 无 AOE 能力 | AOE 场景弱势，单体 BOSS 强势 |
| 木 | 持续+恢复最强 | 爆发不足 | DOT 可被驱散，恢复受「疗伤上限」限制 |
| 水 | 控制最强 | 伤害最低 | 控制对 BOSS 无效（免疫），PVP 有递减 |
| 火 | AOE 最强 | 单体最低 | 法力消耗高，对火抗目标无力 |
| 土 | 防御最强 | 输出最低 | 打不中人就没有作用，被高穿透克制 |
| 雷（变异） | 最全面 | 获取难度最高 | 变异灵根概率极低（< 1%），可通过后天机缘 |

**五行平衡监测指标：**

```
每月数据检查：
  1. 各属性在 PVE 中的胜率（目标：45-55%）
  2. 各属性在 PVP 中的胜率（目标：48-52%）
  3. 各属性玩家数量占比（评价是否某属性被过度优化）
  4. 属性克制带来的胜率偏移（被克时胜率不应低于 30%）
```

### 4.3 境界差平衡

```
同境界战斗：胜负由装备/技能/操作决定（各占约 1/3）
差 1 小层：高阶胜率约 55-60%（装备可以弥补）
差 1 大境界：高阶胜率约 75-80%（克制属性 + 顶级装备可逆转）
差 2 大境界：高阶胜率约 95%（几乎不可逆转，符合原著设定）

越级挑战补偿机制（保护低阶玩家）：
  1. 低阶玩家被高阶击杀时，装备掉落率降低（差 1 大境界 -50%）
  2. 低阶玩家主动发起生死斗时，可选择「被挑战保护」（掉落保护 + 属性临时 +10%）
  3. 野外击杀低境界者获得「以大欺小」业力标记，积累过多会触发天劫增强
```

### 4.4 经济平衡

战斗系统的收支平衡直接影响游戏经济：

|---------|---------|-------|:-------:|

## 五、战斗系统 LPC 实现框架

### 5.1 核心战斗流程

```c
// 战斗循环主流程（由 COMBAT_D 守护进程调度）
// 每 tick（1 回合 = 游戏内 3 秒）执行一次

int combat_tick(object attacker, object target) {
    int action_type = select_action(attacker, target);
    
    switch (action_type) {
        case ACTION_ATTACK:
            return perform_attack(attacker, target);
        case ACTION_SKILL:
            return perform_skill(attacker, target, attacker->get_current_skill());
        case ACTION_DEFEND:
            return perform_defend(attacker, target);
        case ACTION_MOVE:
            return perform_move(attacker, attacker->get_aiming_position());
        case ACTION_ARRAY:
            return perform_array(attacker);
        case ACTION_FLEE:
            return perform_flee(attacker);
        default:
            return 0;
    }
}

// 伤害计算
int calc_damage(object attacker, object target, mapping skill_info) {
    int base_damage = skill_info["damage"];
    int attack_power = attacker->query_attack_power();
    int defense = target->query_defense();
    
    // 属性克制系数
    float element_mod = calc_element_modifier(
        skill_info["element"],
        target->query("element")
    );
    
    // 境界系数
    float realm_mod = calc_realm_modifier(
        attacker->query("realm"),
        target->query("realm")
    );
    
    // 灵根加成
    float lingen_mod = calc_lingen_bonus(
        attacker->query("lingen"),
        skill_info["element"]
    );
    
    // 最终伤害
    int damage = to_int(base_damage * attack_power / 100.0 
                      * element_mod * realm_mod * lingen_mod
                      * (0.95 + random(11) / 100.0));
    
    return damage;
}
```

### 5.2 五行克制 LPC 实现

```c
// 五行克制系数表
#define ELEMENT_GOLD    1
#define ELEMENT_WOOD    2
#define ELEMENT_WATER   3
#define ELEMENT_FIRE    4
#define ELEMENT_EARTH   5
#define ELEMENT_THUNDER 6  // 变异
#define ELEMENT_ICE     7  // 变异
#define ELEMENT_WIND    8  // 变异

// 克制表：attacker -> target 的系数
mapping element_table = ([
    ELEMENT_GOLD:   ([ ELEMENT_WOOD: 1.5, ELEMENT_FIRE: 0.7 ]),
    ELEMENT_WOOD:   ([ ELEMENT_EARTH: 1.5, ELEMENT_GOLD: 0.7 ]),
    ELEMENT_WATER:  ([ ELEMENT_FIRE: 1.5, ELEMENT_EARTH: 0.7 ]),
    ELEMENT_FIRE:   ([ ELEMENT_GOLD: 1.5, ELEMENT_WATER: 0.7 ]),
    ELEMENT_EARTH:  ([ ELEMENT_WATER: 1.5, ELEMENT_WOOD: 0.7 ]),
    // 变异属性
    ELEMENT_THUNDER:([ ELEMENT_WATER: 1.8, ELEMENT_ICE: 1.5, ELEMENT_GOLD: 1.2, ELEMENT_EARTH: 0.7 ]),
    ELEMENT_ICE:    ([ ELEMENT_FIRE: 1.5, ELEMENT_WIND: 1.3, ELEMENT_THUNDER: 0.6 ]),
    ELEMENT_WIND:   ([ ELEMENT_EARTH: 1.5, ELEMENT_THUNDER: 1.2, ELEMENT_ICE: 0.7 ]),
]);

float calc_element_modifier(int att_elem, int def_elem) {
    if (undefinedp(element_table[att_elem])) return 1.0;
    if (undefinedp(element_table[att_elem][def_elem])) return 1.0;
    return element_table[att_elem][def_elem];
}
```
