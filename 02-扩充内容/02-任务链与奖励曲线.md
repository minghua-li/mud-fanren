# 02：任务链与奖励曲线系统（合理扩充）

> **本文档是对 [[quests/1G-任务副本奇遇]] 的任务体系游戏化扩充**，聚焦玩家如何通过各类型任务推进游戏进程——主线/支线/日常周常/成就系统的玩法设计、奖励数值曲线与境界对齐、刷新规则与经济平衡。
> 主线剧情与副本秘境的设计详见 [[quests/1G-任务副本奇遇]]，声望与势力内容见 [[factions/1D-门派种族声望]]，经济体系见 [[items/1E-法宝丹药经济]]，境界与修炼见 [[cultivation/CULTIVATION_SYSTEM]]。

基于《凡人修仙传》剧本设定，面向 MUD 游戏化的任务与奖励体系设计。本文档的内容属于「合理扩充」范畴。

## 一、任务体系总览

### 1.1 任务分类

| 任务类型 | 可重复性 | 刷新规则 | 核心产出 | 典型例子 |
|---------|:-------:|---------|---------|---------|
| **主线任务** | 一次性 | 剧情驱动，不可回流 | 境界突破、关键功法、区域解锁 | 入七玄门→血色禁地→虚天殿 |
| **支线任务** | 部分可重做 | 手动触发/剧情分支 | 装备、丹药、声望、技艺 | 墨府恩怨、太南谷坊市 |
| **日常任务** | 每日刷新 | 0:00 重置，可放弃重接 | 基础修为、少量灵石、门派贡献 | 采集灵药、猎杀妖兽、门派杂务 |
| **周常任务** | 每周刷新 | 周一 0:00 重置 | 修为丹、灵石袋、声望令 | 门派守卫战、势力任务周常 |
| **成就任务** | 一次性 | 达成条件自动完成 | 称号、外观、特殊属性 | 百战修罗、藏书万卷、渡劫达人 |
| **奇遇任务** | 一次性 | 随机触发/条件解锁 | 特殊法宝、稀有丹药 | 掌天瓶认主、万年灵乳发现 |
| **势力任务** | 可重复（有限制） | 按声望等级解锁 | 势力声望、限定物品 | 巡查星海、追剿海盗 |

**任务链机制**（接 quests/1G 体系）：

| 链类型 | 说明 | 适用范围 |
|-------|------|---------|
| **串行链** | 前置完成后自动接续下一个，呈线性 | 主线任务（严格串行） |
| **分支链** | 同一节点可选不同方向，影响后续节点开放 | 支线任务（如越国可选留在越国或前往乱星海） |
| **并行链** | 多条任务链可同时推进，互不阻塞 | 主线+支线+日常可同时持有 |
| **条件链** | 满足声望/境界/物品条件才会解锁后续节点 | 势力任务、高级日常任务 |
| **限时链** | 有游戏内时间限制，超时失败 | 血色禁地（30天游戏内）、限时活动 |

### 1.2 任务接取方式

| 接取方式 | 说明 | 典型场景 |
|---------|------|---------|
| **NPC 对话** | 与特定 NPC 对话触发 | 主线任务推进、支线任务开启 |
| **自动触发** | 满足条件后系统自动推送 | 主线章节过渡、成就达成 |
| **道具触发** | 持有/使用特定道具时触发 | 虚天残图→虚天殿任务 |
| **区域进入** | 进入特定区域时触发 | 副本入口→副本任务 |
| **声望解锁** | 达到声望等级后 NPC 开放 | 星宫声望≥友善→星宫任务链 |
| **时间触发** | 游戏内特定时间段自动出现 | 每日刷新日常、每周重置周常 |
| **成就里程碑** | 达成特定成就后解锁进阶任务 | 完成「筑基」成就→元婴突破指引 |

## 二、主线任务链

### 2.1 主线章节结构

主线按小说剧情分为五大篇章，每个篇章内由 10-15 个串行任务构成：

| 篇章 | 境界跨度 | 任务数 | 核心副本 | 终章奖励 |
|:----:|---------|:-----:|---------|---------|
| **第零章·凡人篇** | 凡人→炼气13层 | 11 | 七玄门密室（夺舍事件） | 称号「初入修仙」、长春功第十三层的领悟 |
| **第一章·越国篇** | 炼气后期→结丹初期 | 13 | 血色禁地（筑基期副本） | 称号「越国风云」、跨界传送阵使用权限 |
| **第二章·乱星海篇** | 结丹初期→元婴后期 | 10 | 虚天殿（结丹-元婴副本） | 称号「星海霸主」、天星城永久洞府 |
| **第三章·灵界篇** | 化神→大乘 | 10 | 地渊/广寒界/魔金山脉 | 称号「灵界传奇」、大乘突破心得 |
| **终章·飞升篇** | 大乘→真仙 | 6 | 大天劫·三灾九难 | 称号「飞升上界」、北寒仙域入口 |

**主线任务总数量**：约 50 个串行任务（不计分支）。

### 2.2 主线任务接续与防跳过机制

```
主线章节切换规则：
┌──────────────────────────────────────────────────┐
│  上一章末任务完成 → 检测玩家境界达标 →            │
│  ├─ 达标 → 自动触发下一章起始任务                    │
│  └─ 不达标 → 停留在当前章节，可自由做支线/日常       │
│                                                     │
│  跨章条件：                                          │
│  第零章→第一章：炼气≥7层 + 完成「离别七玄门」        │
│  第一章→第二章：结丹初期 + 完成「越国终章」          │
│  第二章→第三章：化神期 + 完成「乱星海终章」          │
│  第三章→终章：  大乘期 + 完成「灵界终章」            │
└──────────────────────────────────────────────────┘
```

**防跳过设计**：
- 主线任务之间的境界门槛确保玩家不会越级通主线
- 关键任务奖励含境界突破必需道具（如筑基丹、凝液丹）
- 跳过主线 = 跳过对应区域/副本解锁权限，后续无法正常推进

### 2.3 主线奖励曲线

| 章节 | 任务平均经验 | 灵石范围 | 关键物品掉落 | 声望产出 |
|:----:|:----------:|:-------:|-------------|---------|
| 凡人篇 | 100~500 | 10~50 | 入门功法、基础丹药 | 七玄门声望+10~50 |
| 越国篇 | 1,000~8,000 | 100~800 | 筑基丹、法器、丹药配方 | 黄枫谷声望+20~80 |
| 乱星海篇 | 10,000~80,000 | 1,000~8,000 | 古宝、补天丹、灵石袋 | 天星城声望+30~100 |
| 灵界篇 | 500,000~5,000,000 | 50,000~200,000 | 通天灵宝、玄天残片 | 灵界种族声望+50~200 |
| 飞升篇 | 10,000,000+ | 1,000,000+ | 仙器胚、仙界秘法 | — |

**设计原则**：主线是玩家最重要的境界突破路径，奖励集中在「境界突破必需物」和「区域解锁权」上——不依赖主线给出大量灵石/材料，让支线和日常承担资源供给角色。

### 2.4 主线分支节点

| 节点 | 分歧选项 | 影响范围 | 可逆性 |
|------|---------|---------|:-----:|
| **1.6 拜入宗门** | 黄枫谷 / 掩月宗 / 灵兽山等七派 | 后续任务线、功法获取、声望体系 | 不可逆（但可转投） |
| **1.13 越国去向** | 立即前往乱星海 / 留在越国做支线 | 区域解锁顺序 | 可选（可随时触发离去） |
| **2.5 阵营选择** | 加入星宫 / 逆星盟 / 保持中立 | 副本准入、势力任务、声望增减 | 可叛变（有惩罚） |

## 三、支线任务系统

### 3.1 支线任务分类

| 支线类型 | 数量规划 | 触发条件 | 产出特色 |
|---------|:------:|---------|---------|
| **角色支线** | 每重要NPC 1~2条 | 声望达标/特定时间 | 专属功法、NPC 好感、特殊道具 |
| **场景支线** | 每区域 3~5条 | 区域解锁+境界达标 | 装备、丹药、区域声望 |
| **收集支线** | 全局 10~15条 | 特殊物品持有 | 称号、限量装备、趣味道具 |
| **隐藏支线** | 全局 5~8条 | 特定行为/极低概率事件 | 唯一称号、强力法宝 |
| **门派支线** | 每派 3~5条 | 门派贡献达标 | 门派高阶功法、门派限定量产 |

**支线总数量设计目标**：150~200 条，覆盖全书主要剧情节点，确保玩家在主线的任意阶段都有 5~10 条可接支线。

### 3.2 支线触发机制

```lpc
// 支线触发条件模型
mapping side_quest_trigger = ([
  "id":           "side_quest_mo_fu_en_yuan",
  "type":         TRIGGER_NPC_DIALOG,
  "npc":          "嘉元城·墨府管家",
  "conditions":   ([
    "min_level":    ({ "炼气", "7层" }),
    "max_level":    ({ "筑基", "后期" }),      // 超过则提示"你对此已不感兴趣"
    "reputation":   ([ "嘉元城": 100 ]),
    "area_access":  "嘉元城",
  ]),
  "chain_info":   ([
    "pre_quest":    null,                       // 无前置
    "next_quests":  ({ "side_quest_mo_girl_1", "side_quest_mo_girl_2" }), // 分支
    "branch_point": true,                       // 是分支节点
  ]),
]);
```

**动态支线缩放的境界上限**：超过建议境界上限后，支线的经验奖励按比例衰减：

```
衰减公式：实际奖励 = 基准奖励 × max(0.1, 1 - (玩家境界 - 建议上限) / 5级)
  示例：筑基后期的玩家完成建议「炼气期」的支线
    实际奖励 = 基准 × max(0.1, 1 - (3) / 5) = 基准 × 0.4
```

**目的**：鼓励玩家在本境界段完成对应支线，避免后期回头碾压低级内容获取不公平收益。

### 3.3 支线奖励曲线

| 支线建议境界 | 单条经验范围 | 灵石范围 | 声望范围 | 特殊产出概率 |
|:----------:|:----------:|:-------:|:-------:|:----------:|
| 炼气期 | 200~1,000 | 20~100 | 10~30 | 5%（白装/基础丹药） |
| 筑基期 | 1,000~5,000 | 100~500 | 20~50 | 10%（法器/中品丹药） |
| 结丹期 | 10,000~60,000 | 500~5,000 | 30~80 | 15%（法宝/上品丹药） |
| 元婴期 | 60,000~300,000 | 5,000~20,000 | 50~100 | 20%（古宝/稀有材料） |
| 化神期 | 300,000~1,500,000 | 20,000~100,000 | 60~120 | 25%（灵宝/秘境卷轴） |
| 炼虚期+ | 1,500,000~5,000,000 | 100,000~500,000 | 80~150 | 30%（通天灵宝/玄天残片） |

## 四、日常与周常任务系统

### 4.1 日常任务

#### 4.1.1 日常任务类型

| 任务名 | 内容 | 建议境界 | 耗时 | 核心奖励 |
|-------|------|:-------:|:---:|---------|
| **采集灵药** | 在指定野外区域采集 N 株灵药 | 炼气~结丹 | 5~10min | 修为+灵石+灵药素材 |
| **猎杀妖兽** | 击杀 N 只特定妖兽 | 炼气~元婴 | 5~15min | 修为+妖兽材料+内丹 |
| **门派杂务** | 协助门派完成简单任务（跑腿/巡逻/清洁） | 炼气~筑基 | 3~5min | 门派贡献+少量修为 |
| **炼制任务** | 提交 N 个指定丹药/法器 | 筑基~元婴 | 10~20min | 门派贡献+稀有材料兑换券 |
| **坊市交易** | 在指定坊市完成交易/跑商 | 炼气~结丹 | 5~10min | 灵石+商会声望 |
| **送信任务** | 在指定区域之间递送物品/信息 | 炼气~筑基 | 3~8min | 修为+声望 |
| **采矿任务** | 在矿脉采集 N 份矿石 | 筑基~元婴 | 5~10min | 矿石材料+修为 |
| **巡山任务** | 巡查指定路线，清剿沿路怪物 | 筑基~结丹 | 10~15min | 门派贡献+修为 |

#### 4.1.2 日常任务刷新与接取规则

| 规则 | 说明 |
|------|------|
| **刷新时间** | 每日 0:00（游戏内/现实时间二选一） |
| **每日上限** | 每个玩家每天可接 8~12 个日常任务（按境界递增） |
| **任务池** | 每个境界段各有 10~15 种日常模板，每天随机抽取 5~8 个可接 |
| **放弃惩罚** | 放弃日常任务 5 分钟内不可接新日常，每日最多放弃 3 次 |
| **质量分级** | 普通（绿色）/ 优秀（蓝色）/ 稀有（紫色）日常，稀有日常奖励×2~×3 |
| **VIP 加成** | 连续完成日常 ≥7 天 → 第 7 天奖励×1.5（中断重置） |

**每日可接日常数按境界递增**：

| 境界 | 每日可接数 | 稀有日常概率 |
|:---:|:--------:|:----------:|
| 炼气期 | 8 | 5% |
| 筑基期 | 9 | 8% |
| 结丹期 | 10 | 12% |
| 元婴期 | 11 | 15% |
| 化神期+ | 12 | 20% |

#### 4.1.3 日常任务奖励公式

```
日常任务基础修为奖励 = 境界基准值 × 任务难度系数 × (1 + 连续天数 × 0.05)
```

| 境界 | 境界基准值 | 普通系数 | 优秀系数 | 稀有系数 |
|:---:|:--------:|:-------:|:-------:|:-------:|
| 炼气期 | 50 | 1.0 | 1.5 | 3.0 |
| 筑基期 | 200 | 1.0 | 1.5 | 3.0 |
| 结丹期 | 1,000 | 1.0 | 1.5 | 3.0 |
| 元婴期 | 5,000 | 1.0 | 1.5 | 3.0 |
| 化神期 | 20,000 | 1.0 | 1.5 | 3.0 |
| 炼虚期 | 80,000 | 1.0 | 1.5 | 3.0 |
| 合体期 | 300,000 | 1.0 | 1.5 | 3.0 |
| 大乘期 | 1,000,000 | 1.0 | 1.5 | 3.0 |

**日常灵石基础模型**：修为奖励的 20%~30%，最低 10 灵石，按境界等比放大。

### 4.3 日常/周常的境界缩放机制

当玩家的境界超过日常/周常的建议范围时，奖励会自动缩放保持有效性：

```lpc
// 动态奖励缩放
int calc_daily_reward(string quest_type, mapping player) {
    int base_reward = quest_template[quest_type]["base_reward"];
    int realm_idx = player["realm_index"];         // 玩家当前境界索引
    int quest_realm = quest_template[quest_type]["realm_index"];
    float scale;
    
    if (realm_idx == quest_realm)
        scale = 1.0;                               // 同境界：100%奖励
    else if (realm_idx < quest_realm)
        scale = 0.5 + 0.5 * (realm_idx / quest_realm); // 低境界玩家能做高难度日常？限制为不可接
    else
        scale = pow(0.7, realm_idx - quest_realm); // 高境界做低日常：衰减
    
    // 保证最低下限（30%），不归零
    return to_int(base_reward * max(0.3, scale));
}
```

**境界差距限制**：玩家与日常任务建议境界差距超过 2 个大境界时，该日常不再对该玩家出现。

## 六、奖励曲线数值模型

### 6.1 玩家日常产出模型

一个活跃玩家的每日/周/月资源获取总量估算（以结丹初期为例）：

#### 每日产出（结丹初期）

| 产出类型 | 日常任务 | 挂机修炼 | 其他（副本/交易/支线） | 日总计 |
|---------|:-------:|:-------:|:-------------------:|:-----:|
| 修为经验 | 8,000~15,000 | 5,000~8,000 | 10,000~30,000 | 23,000~53,000 |
| 灵石 | 2,000~4,000 | 0 | 5,000~20,000 | 7,000~24,000 |
| 门派贡献 | 100~200 | 0 | 50~200 | 150~400 |
| 材料 | 3~8份 | 0 | 5~30份 | 8~38份 |

#### 每周产出（结丹初期 → 结丹中期所需资源对比）

| 资源项 | 周常可获 | 日常×7可获 | 周总产出 | 结丹初→中所需 |
|-------|:-------:|:---------:|:-------:|:------------:|
| 修为 | 30,000~60,000 | 56,000~105,000 | 86,000~165,000 | ~500,000 |
| 灵石 | 5,000~15,000 | 14,000~28,000 | 19,000~43,000 | ~100,000（含消耗） |
| 修炼材料 | 5~15份 | 21~56份 | 26~71份 | ~200份 |

**设计结论**：日常是稳定基础积累，副本/秘境/支线才是质变的主要来源。目标是让活跃玩家约 2~3 周可突破一个小境界，3~4 个月突破一个大境界（以结丹期计）。

### 6.2 任务奖励 vs 境界突破成本对齐

将任务奖励与[[cultivation/CULTIVATION_SYSTEM]]和[[cultivation/1C-修仙境界功法]]中的突破成本对齐：

#### 小境界突破（功法层数）

| 功法层数区间 | 估算修为需求 | 单纯靠日常所需天数 | 靠日常+支线混搭 | 推荐组成 |
|:----------:|:----------:|:--------------:|:-------------:|---------|
| 1~5层 | 2,000~10,000 | 2~4天 | 1~2天 | 主线60% + 日常30% + 其他10% |
| 6~10层 | 15,000~50,000 | 3~5天 | 2~3天 | 主线40% + 日常30% + 支线30% |
| 11~15层（炼气大圆满） | 200,000~500,000 | 10~20天 | 7~14天 | 主线30% + 日常20% + 支线20% + 副本30% |
| 筑基期层数 | 100,000~500,000/层 | 3~7天/层 | 2~5天/层 | 日常40% + 支线20% + 副本40% |
| 结丹期层数 | 500,000~3,000,000/层 | 5~12天/层 | 3~8天/层 | 日常30% + 副本50% + 其他20% |

#### 大境界突破消耗（以结丹期为例）

| 突破所需 | 估算总量 | 任务可提供占比 | 其他来源 |
|---------|:------:|:-----------:|---------|
| 修为积累 | ~5,000,000 | 40%（日常+支线） | 副本30%、挂机20%、丹药10% |
| 突破丹药 | 筑基丹/凝液丹×1 | 主线奖励（一次性） | 炼丹/购买 |
| 突破灵物 | 根据灵根品质 | 主线/奇遇提供 | 副本掉落、交易 |
| 心魔关卡 | 战斗通关 | 主线固有 | — |

### 6.3 任务奖励 vs 经济系统对齐

任务体系与[[items/1E-法宝丹药经济]]中的经济模型要保持一致，避免任务产出打破经济平衡：

#### 灵石供给占比约束

```
游戏总灵石产出中，各渠道占比上限：
  日常任务：≤30%     支线任务：≤15%    主线任务：≤10%
  副本产出：≤30%      交易/跑商：≤10%   NPC出售：≤5%
```

**任务灵石产出占总灵石比例建议**：40%~50%（过低则任务货币激励不足，过高则交易失去意义）。

#### 修为经验供给占比约束

```
游戏总修为经验产出中，各渠道占比上限：
  日常任务：≤35%      支线任务：≤10%     主线任务：≤15%
  挂机修炼：≤20%      副本战斗：≤10%      丹药：≤10%
```

**控制理由**：日常占修为的主要部分（稳定感），但突破的「质变瞬间」应来自主线/丹药/副本的高价值产出。

#### 每日收益 vs 境界突破时间预期

|:----:|:--------------:|:------------:|:-------:|:------------:|:-------:|

| **筑基期** | 1,000~5,000 | 100,000~500,000 | 7~20天 | 2,000,000~5,000,000 | 60~120天 |
| **结丹期** | 8,000~30,000 | 500,000~3,000,000 | 10~30天 | 10,000,000~30,000,000 | 90~180天 |
| **元婴期** | 30,000~150,000 | 3,000,000~15,000,000 | 15~40天 | 50,000,000~200,000,000 | 120~240天 |
| **化神期** | 150,000~500,000 | 15,000,000~50,000,000 | 20~60天 | 200,000,000~1,000,000,000 | 150~300天 |
| **炼虚期** | 500,000~2,000,000 | 50,000,000~200,000,000 | 30~70天 | — | — |
| **合体期** | 2,000,000~8,000,000 | 200,000,000~800,000,000 | 40~80天 | — | — |
| **大乘期** | 8,000,000~20,000,000 | 800,000,000~∞ | 60~120天 | — | — |

#### 活跃度梯度模型

不同活跃度的玩家，其成长速度应显著不同——但差距不应大到让轻度玩家完全失去驱动力：

| 玩家类型 | 日均在线 | 日均修为获取 | 结丹→元婴周期 | 策略 |
|---------|:------:|:----------:|:----------:|------|
| **轻度**（每日 30min） | 1h | 基准×0.5 | 6~12月 | 日常完成率 30%，依赖挂机 |

| **活跃**（每日 3-4h） | 3h | 基准×2.0 | 1.5~3月 | 日常全清+周常+部分支线 |
| **硬核**（每日 5h+） | 5h | 基准×3.5 | 1~2月 | 全清+大量副本+支线全收集 |

**设计约束**：硬核玩家不应比常规玩家快超过 3 倍（防代练/脚本碾压）。每日挂机收益设上限，日常任务设次数上限，副本设 CD。

## 七、平衡控制与防滥用机制

### 7.1 任务完成频率控制

| 控制措施 | 具体规则 | 设计目的 |
|---------|---------|---------|
| **日常次数上限** | 每个玩家每天最多完成 8~12 个日常 | 防止脚本无限刷日常 |
| **每日同类上限** | 同类型日常最多完成 3 个/天 | 防止刷单一高收益日常 |
| **周常次数上限** | 每周 3~5 个周常，存储不累计 | 确保每周的参与感 |
| **放弃限制** | 每日最多放弃 3 次，超时不可放弃 | 防止刷稀有日常的「刷新流」 |
| **总任务上限** | 同时持有任务上限：20 个 | 防止任务列表过长 |
| **冷却机制** | 完成日常后到下次刷新间有 1h 冷却（可跳过） | 防止集中刷取 |

### 7.2 防脚本与自动化

| 措施 | 实现方式 | 力度 |
|------|---------|:---:|
| **验证码触发** | 连续完成 5 个任务后弹出验证 | 低频率 |
| **行为分析** | 检测固定间隔模式/完全相同操作序列 | 后台标记 |
| **随机目标** | 日常的采集点/怪物坐标每天微调 | 轻量级 |
| **任务多样性** | 玩家不会连续两天接到完全相同的日常组合 | 持续 |
| **时间变量** | 部分日常要求现任务时间≥X 秒（防止瞬间完交） | 软约束 |

### 7.3 奖励通胀保护

| 风险 | 缓解措施 |
|------|---------|
| **灵石通胀** | 日常灵石产出设置上限（不随境界无限增长）；灵石回收渠道（洗灵池、传送费、炼丹成本）维持平衡 |
| **修为膨胀** | 境界间修为需求指数增长（×5~×10），高于奖历线性增长（×3~×5）；高境界日常的绝对修为更高，但相对百分比贡献更低 |
| **装备贬值** | 日常不产出高品质装备，只产出材料/基础装备；法宝/灵宝级装备限制在副本/主线产出 |
| **物品堆积** | 日常产出绑定的低阶物品可回收换积分（积分商店兑换当前境界需要的物资） |

### 7.4 任务系统核心平衡约束

| 约束 | 规则 | 设计目的 |
|------|------|---------|
| **上限设定** | 所有可重复任务的完成次数/频率均有硬上限 | 防无限刷 |
| **奖励递减** | 同类/同区域任务连续完成后奖励逐渐衰减至 30% | 鼓励多样性 |
| **境界锚定** | 任务奖励以境界倍数而非绝对数值成长 | 全阶段适用 |
| **价值对齐** | 任务产出价值与[[items/1E-法宝丹药经济]]的物价模型一致 | 防经济失衡 |
| **回收通道** | 任务产出的低级物品可通过回收系统转换为高阶资源 | 控制物品堆积 |
| **社交奖励** | 组队完成日常/周常时额外获得 10%~20% 奖励 | 鼓励社交 |

### 7.5 境界突破保护机制

```
当玩家在当前境界段「卡住」超过建议周期上限时：
┌──────────────────────────────────────────────┐
│  触发「天道酬勤」保护：                           │
│  条件：连续 14 天未突破小境界 + 活跃天数 ≥ 10     │
│  效果：日常任务修为奖励+30%，持续至突破            │
│                                                  │
│  触发「瓶颈松动」保护：                           │
│  条件：突破失败 ≥ 3 次                             │
│  效果：下次突破概率 +15%（不与其他概率加成叠加封顶） │
│                                                  │
│  触发「师尊指点」引导：                           │
│  条件：当前境界停留 ≥ 建议周期的 1.5 倍             │
│  效果：系统在完成日常时推送突破指引（需要什么材料、   │
```

## 九、实现优先级建议

| 优先级 | 子系统 | 原因 | 预估工作量 |
|:-----:|-------|------|:---------:|
| **P0** | 日常任务系统 | 最基础的经济产出来源，玩家上线驱动力 | 2~3天 |

| **P2** | 分支链/条件链 | 复杂度较高，可在主线框架稳定后迭代 | 3~5天 |
| **P2** | 隐藏成就系统 | 非核心玩法 | 1~2天 |
