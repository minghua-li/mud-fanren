# 设计文档关联关系

> 本文档描述 `02-扩充内容/` 下各设计文档之间的交叉引用与依赖关系，供实现时按图索骥。

## 关联矩阵

| 系统 A | 系统 B | 关联说明 |
|--------|--------|----------|
| 🌿 **灵根养成** (#10) | ⚔️ **战斗机制** (#11) | 灵根属性（金/木/水/火/土/变异）决定五行法术伤害加成系数；突破境界解锁更高级技能槽位 |
| 🌿 **灵根养成** (#10) | 🗺️ **区域玩法** (#12) | 突破所需材料/试炼分布在特定区域（如血色禁地、虚天殿）；境界决定玩家可进入的区域层级 |
| 🌿 **灵根养成** (#10) | 📜 **任务链** (#14) | 境界突破任务是主线任务的核心节点；突破前置条件通过任务链引导 |
| 🌿 **灵根养成** (#10) | 💰 **经济系统** (#15) | 洗灵池费用、突破消耗灵石/丹药影响经济流速；突破加速道具是经济重要消耗品 |
| ⚔️ **战斗机制** (#11) | 🗺️ **区域玩法** (#12) | 不同区域设有特定战斗规则（如禁空阵、削弱 Buff）；秘境副本包含 BOSS 战多阶段机制 |
| ⚔️ **战斗机制** (#11) | 🤝 **声望互动** (#13) | 高声望解锁高级 PVP 段位与竞技场资格；帮战/势力战依赖阵法站位和多人战斗系统 |
| ⚔️ **战斗机制** (#11) | 📜 **任务链** (#14) | 主线战斗关卡、支线击杀任务、日常讨伐任务依赖战斗系统实现 |
| ⚔️ **战斗机制** (#11) | 💰 **经济系统** (#15) | 战斗掉落装备/材料/灵石直接影响经济产出；PVP 胜场奖励消耗经济库存 |
| 🗺️ **区域玩法** (#12) | 🤝 **声望互动** (#13) | 各区域对应不同势力的声望体系（如灵界种族外交博弈）；区域资源产出影响势力发展 |
| 🗺️ **区域玩法** (#12) | 📜 **任务链** (#14) | 区域解锁新任务线（如灵界篇支线）；任务链引导玩家探索各级区域 |
| 🗺️ **区域玩法** (#12) | 💰 **经济系统** (#15) | 传送费用体系、区域物价差异、秘境产出物资直接参与经济循环 |
| 🤝 **声望互动** (#13) | 📜 **任务链** (#14) | 声望门槛解锁高级任务线（如势力专属任务）；忠臣/死士声望奖励阶梯基于任务链系统 |
| 🤝 **声望互动** (#13) | 💰 **经济系统** (#15) | 声望商店折扣定价、势力贡献兑换、帮战资源消耗影响经济平衡 |
| 📜 **任务链** (#14) | 💰 **经济系统** (#15) | 任务产出灵石/材料影响经济总产出；成就奖励（累计/段位加成）对经济系统有周期性注入效应 |
| 🛠️ **开发落地** (#17) | 🌿 灵根 / ⚔️ 战斗 / 🗺️ 区域 / 🤝 声望 / 📜 任务链 / 💰 经济 | #17 跨系统集成实施计划涵盖全部 6 个子系统的 P0→P3 开发路线、依赖矩阵、代码文件映射 |
